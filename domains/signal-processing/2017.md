# Deep Learning for Signal Processing — 2017

- **An Introduction to Deep Learning for the Physical Layer** — IEEE TCCN 2017 [`Communications`]
  [[Paper](https://arxiv.org/abs/1702.00832)]
  Recast the entire communications system as an autoencoder trained end-to-end, jointly optimizing transmitter and receiver for block error rate minimization.

- **Compressed Sensing using Generative Models** — ICML 2017 [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1703.03208)] [[Code](https://github.com/AshishBora/csgm)]
  Replaced sparsity assumptions with generative model priors for compressed sensing, achieving accurate reconstruction with 5-10x fewer measurements than Lasso.

- **AMP-Inspired Deep Networks for Sparse Linear Inverse Problems** — IEEE TSP 2017 [`Algorithm Unrolling`] [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1612.01183)] [[Code](https://github.com/mborgerding/onsager_deep_learning)]
  Proposed Learned AMP and Learned VAMP by unfolding approximate message passing with Onsager correction into trainable deep networks for sparse recovery.

- **Learned D-AMP: Principled Neural Network based Compressive Image Recovery** — NeurIPS 2017 [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1704.06625)] [[Code](https://github.com/ricedsp/D-AMP_Toolbox)]
  Designed a neural network mimicking denoising-based approximate message passing for compressive image recovery, running 50x faster than BM3D-AMP.

- **Learning to Invert: Signal Recovery via Deep Convolutional Networks** — ICASSP 2017 [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1701.03891)]
  Proposed DeepInverse, a deep convolutional network that directly learns the inverse mapping from compressive measurements to signals without iterative optimization.

- **Deep Learning with Convolutional Neural Networks for EEG Decoding and Visualization** — Human Brain Mapping 2017 [`Biomedical`]
  [[Paper](https://arxiv.org/abs/1703.05051)] [[Code](https://github.com/braindecode/braindecode)]
  Showed that deep ConvNets with batch normalization and cropped training match or exceed FBCSP for EEG decoding, with novel visualization of learned spectral-spatial features.

- **Remote Sensing Image Scene Classification: Benchmark and State of the Art** — Proceedings of the IEEE 2017 [`Radar & Remote Sensing`]
  [[Paper](https://arxiv.org/abs/1703.00121)]
  Introduced the NWPU-RESISC45 benchmark (31,500 images, 45 scene classes) and provided comprehensive evaluation of deep learning methods for remote sensing scene classification.
