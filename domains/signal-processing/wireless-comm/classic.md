# Wireless & Communication Signals — Classic Papers

Foundational and pioneering works in deep learning for wireless communications.

- ⭐ **An Introduction to Deep Learning for the Physical Layer** — IEEE TCCN 2017 [`Communications`]
  [[Paper](https://arxiv.org/abs/1702.00832)]
  Recast the communications system as an autoencoder for end-to-end learning of transmitter and receiver, establishing the deep learning for physical-layer communications paradigm.

- ⭐ **Convolutional Radio Modulation Recognition Networks** — EANN 2016 [`Communications`]
  [[Paper](https://arxiv.org/abs/1602.04105)]
  First applied deep CNNs on raw IQ samples for automatic modulation recognition, demonstrating learned features outperform expert-crafted ones at low SNR.
