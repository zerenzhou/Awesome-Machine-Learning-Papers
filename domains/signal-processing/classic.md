# Deep Learning for Signal Processing — Classic Papers

Foundational and pioneering works at the intersection of deep learning and signal processing.

- ⭐ **Learning Fast Approximations of Sparse Coding** — ICML 2010 [`Algorithm Unrolling`]
  [[Paper](https://icml.cc/Conferences/2010/papers/449.pdf)]
  Proposed LISTA (Learned ISTA) by unrolling the iterative shrinkage-thresholding algorithm into a trainable neural network, founding the algorithm unrolling paradigm.

- ⭐ **Deep Unfolding: Model-Based Inspiration of Novel Deep Architectures** — arXiv 2014 [`Algorithm Unrolling`]
  [[Paper](https://arxiv.org/abs/1409.2574)]
  Coined the term "deep unfolding" by proposing to unfold inference iterations of model-based algorithms as layers in a deep network with untied parameters, trained discriminatively.

- ⭐ **An Introduction to Deep Learning for the Physical Layer** — IEEE TCCN 2017 [`Communications`]
  [[Paper](https://arxiv.org/abs/1702.00832)]
  Recast the communications system as an autoencoder for end-to-end learning of transmitter and receiver, establishing the deep learning for physical-layer communications paradigm.

- ⭐ **Convolutional Radio Modulation Recognition Networks** — EANN 2016 [`Communications`]
  [[Paper](https://arxiv.org/abs/1602.04105)]
  First applied deep CNNs on raw IQ samples for automatic modulation recognition, demonstrating learned features outperform expert-crafted ones at low SNR.

- ⭐ **EEGNet: A Compact Convolutional Neural Network for EEG-Based Brain-Computer Interfaces** — Journal of Neural Engineering 2018 [`Biomedical`]
  [[Paper](https://arxiv.org/abs/1611.08024)] [[Code](https://github.com/vlawhern/arl-eegmodels)]
  Introduced a compact CNN using depthwise and separable convolutions for EEG-based BCI, generalizing across four BCI paradigms with minimal parameters.

- ⭐ **Deep Complex Networks** — ICLR 2018 [`Complex-Valued`]
  [[Paper](https://arxiv.org/abs/1705.09792)] [[Code](https://github.com/ChihebTrabelsi/deep_complex_networks)]
  Provided key building blocks for complex-valued deep networks including complex convolutions, complex batch normalization, and complex weight initialization.
