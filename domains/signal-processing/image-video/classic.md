# Image & Video Signal Processing — Classic Papers

Foundational and pioneering works in learned image/video reconstruction and inverse problems.

- ⭐ **Compressed Sensing using Generative Models** — ICML 2017 [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1703.03208)] [[Code](https://github.com/AshishBora/csgm)]
  Replaced sparsity assumptions with generative model priors for compressed sensing, achieving accurate reconstruction with 5-10x fewer measurements than Lasso — a foundational work that redefined CS with learned priors.
