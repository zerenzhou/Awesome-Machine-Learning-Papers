# Deep Learning for Signal Processing — 2023

- **Diffusion Posterior Sampling for General Noisy Inverse Problems** — ICLR 2023 Spotlight [`Inverse Problems`] [`Diffusion`]
  [[Paper](https://arxiv.org/abs/2209.14687)] [[Code](https://github.com/DPS2022/diffusion-posterior-sampling)]
  Extended diffusion-based solvers to handle general noisy and nonlinear inverse problems by approximating the posterior score via a tractable likelihood term.

- **Ambient Diffusion: Learning Clean Distributions from Corrupted Data** — NeurIPS 2023 [`Inverse Problems`] [`Diffusion`]
  [[Paper](https://arxiv.org/abs/2305.19256)] [[Code](https://github.com/giannisdaras/ambient-diffusion)]
  First diffusion framework that learns clean data distributions from only corrupted/incomplete observations, enabling compressed sensing recovery without clean training data.

- **Model-Based Deep Learning** — Proceedings of the IEEE 2023 [`Algorithm Unrolling`]
  [[Paper](https://arxiv.org/abs/2012.08405)]
  Authoritative tutorial surveying strategies for combining domain knowledge with deep learning, covering learned optimizers, deep unfolding, and DNN-aided inference for signal processing.

- **Beyond Transmitting Bits: Context, Semantics, and Task-Oriented Communications** — IEEE JSAC 2023 [`Communications`]
  [[Paper](https://arxiv.org/abs/2207.09353)]
  Comprehensive tutorial on semantic and task-oriented communications covering information-theoretic foundations, deep JSCC, and learning-based system design for 6G networks.

- **BrainBERT: Self-supervised Representation Learning for Intracranial Recordings** — ICLR 2023 [`Biomedical`] [`Foundation Model`]
  [[Paper](https://arxiv.org/abs/2302.14367)] [[Code](https://github.com/czlwang/BrainBERT)]
  Applied BERT-style masked pre-training to intracranial EEG spectrograms, producing reusable representations that generalize across subjects and reduce labeled data requirements by up to 85%.

- **RingMo: A Remote Sensing Foundation Model with Masked Image Modeling** — IEEE TGRS 2023 [`Radar & Remote Sensing`] [`Foundation Model`]
  [[Paper](https://ieeexplore.ieee.org/document/10105625)]
  Built a 2M-image RS pre-training dataset with density-aware masking, achieving SOTA on 8 benchmarks across scene classification, detection, segmentation, and change detection.
