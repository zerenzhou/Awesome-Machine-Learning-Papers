# Mechanical Fault Diagnosis — 2026

- **BearGen: LLM-Guided Signal Generation Framework for Bearing Fault Diagnosis** — Advanced Engineering Informatics 2026 [`Mechanical Fault Diagnosis`] [`Foundation Model`]
  [[Paper](https://doi.org/10.1016/j.aei.2026.104400)]
  Used an LLM to produce natural-language signal descriptions that condition a diffusion model to synthesize vibration signals on-premises, validated on 8 bearing datasets — establishing the "LLM-as-data-generator" paradigm complementary to classification-oriented LLM-PHM.

- **LoRM: Learning the Language of Rotating Machinery for Self-Supervised Condition Monitoring** — arXiv 2026 [`Mechanical Fault Diagnosis`] [`Foundation Model`]
  [[Paper](https://arxiv.org/abs/2604.05863)] [[Code](https://github.com/Q159753258/LormPHM)]
  Tokenized multi-channel sensor streams (vibration / acoustic / force) into a unified "machine language" sequence and trained an LM with next-token prediction, using prediction error as a health indicator — a direct RmGPT successor with released code.

- **Multimodal Data-Enabled Large Model for Machine Fault Diagnosis towards Intelligent Operation and Maintenance (LMM-FD)** — Journal of Industrial Information Integration 2026 [`Mechanical Fault Diagnosis`] [`Foundation Model`]
  [[Paper](https://www.sciencedirect.com/science/article/abs/pii/S2452414X26000026)]
  Aligned vibration time series with textual fault knowledge through a mechanical knowledge graph inside a multimodal large model, enabling zero-shot generalization to unseen compound faults.

- **Bearing Fault Diagnosis via Topological Data Analysis: Strategic Feature Selection and Algorithm-Dependent Performance under Sample-Size Constraints** — MSSP 2026 [`Mechanical Fault Diagnosis`]
  [[Paper](https://doi.org/10.1016/j.ymssp.2026.114103)]
  Combined topological data analysis features with classical time-domain features and SVM-RBF for the small-sample regime (n=51), reaching 100% in-lab and 73.3% cross-dataset — a deliberate counter-balance to the LLM-heavy 2024–2025 wave.
