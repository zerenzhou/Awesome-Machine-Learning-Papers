# Deep Learning for Signal Processing — 2019

- **Learning to Detect** — IEEE TSP 2019 [`Algorithm Unrolling`] [`Communications`]
  [[Paper](https://arxiv.org/abs/1805.07631)]
  Proposed DetNet by unfolding projected gradient descent into a deep network for MIMO detection, achieving near-optimal performance with learned parameters across channel distributions.

- **Deep Joint Source-Channel Coding for Wireless Image Transmission** — IEEE TCCN 2019 [`Communications`]
  [[Paper](https://arxiv.org/abs/1809.01733)]
  Proposed deep JSCC using CNNs to directly map image pixels to channel symbols, outperforming separation-based JPEG/JPEG2000 + capacity-achieving codes at low SNR.

- **Deep Learning-Based Channel Estimation** — IEEE Communications Letters 2019 [`Communications`]
  [[Paper](https://arxiv.org/abs/1810.05893)]
  Treated time-frequency channel response as a 2D image and applied deep image super-resolution and restoration techniques for pilot-based channel estimation.

- **Deep Compressed Sensing** — ICML 2019 [`Compressed Sensing`]
  [[Paper](https://arxiv.org/abs/1905.06723)]
  Proposed a framework jointly training generators and reconstruction via meta-learning, simultaneously optimizing measurement and recovery for compressed sensing.

- **Cardiologist-Level Arrhythmia Detection and Classification in Ambulatory Electrocardiograms Using a Deep Neural Network** — Nature Medicine 2019 [`Biomedical`]
  [[Paper](https://www.nature.com/articles/s41591-018-0268-3)] [[Code](https://github.com/awni/ecg)]
  Validated that a 34-layer CNN trained on 91,232 single-lead ECGs from 53,549 patients exceeds average cardiologist performance (F1: 0.837 vs. 0.780) in 12-class arrhythmia detection.
