# Deep Learning for Signal Processing — 2016

- **Target Classification Using the Deep Convolutional Networks for SAR Images** — IEEE TGRS 2016 [`Radar & Remote Sensing`]
  [[Paper](https://ieeexplore.ieee.org/document/7460942)]
  Proposed all-convolutional networks (A-ConvNets) without fully connected layers for SAR automatic target recognition on the MSTAR dataset, addressing overfitting from limited training data.

- **Radio Machine Learning Dataset Generation with GNU Radio** — GNU Radio Conference 2016 [`Communications`]
  [[Paper](https://pubs.gnuradio.org/index.php/grcon/article/view/11)]
  Released the RadioML benchmark datasets for radio signal classification tasks, providing common baselines for the emerging radio machine learning community.

- **Deep ADMM-Net for Compressive Sensing MRI** — NeurIPS 2016 [`Algorithm Unrolling`] [`Compressed Sensing`]
  [[Paper](https://papers.nips.cc/paper/6406-deep-admm-net-for-compressive-sensing-mri)] [[Code](https://github.com/yangyan92/Deep-ADMM-Net)]
  Unrolled the ADMM optimization algorithm into a deep network with learnable transforms and shrinkage functions for MRI reconstruction, achieving fast and accurate CS recovery.

- **Full-Capacity Unitary Recurrent Neural Networks** — NeurIPS 2016 [`Complex-Valued`]
  [[Paper](https://arxiv.org/abs/1611.00035)] [[Code](https://github.com/stwisdom/urnn)]
  Proposed full-capacity unitary RNNs that optimize over all unitary matrices via a multiplicative gradient step on the unitary manifold, avoiding vanishing/exploding gradients.
