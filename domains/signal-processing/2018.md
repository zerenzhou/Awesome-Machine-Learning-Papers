# Deep Learning for Signal Processing — 2018

- **Deep Learning-Based Communication Over the Air** — IEEE JSTSP 2018 [`Communications`]
  [[Paper](https://arxiv.org/abs/1707.03384)]
  Demonstrated end-to-end learned autoencoder-based communications over real wireless channels using software-defined radios, validating deep learning for physical-layer design.

- **Over-the-Air Deep Learning Based Radio Signal Classification** — IEEE JSTSP 2018 [`Communications`]
  [[Paper](https://arxiv.org/abs/1712.04578)]
  Conducted comprehensive evaluation of deep learning for radio signal classification including ResNet architectures, across simulated and over-the-air channels with the RadioML 2018.01A dataset.

- **Power of Deep Learning for Channel Estimation and Signal Detection in OFDM Systems** — IEEE WCL 2018 [`Communications`]
  [[Paper](https://arxiv.org/abs/1708.08514)]
  Applied deep learning to jointly perform implicit channel estimation and signal detection in OFDM, bypassing traditional explicit CSI estimation pipelines.

- **Deep Learning for Massive MIMO CSI Feedback** — IEEE WCL 2018 [`Communications`]
  [[Paper](https://arxiv.org/abs/1712.08919)] [[Code](https://github.com/sydney222/Python_CsiNet)]
  Proposed CsiNet, a deep learning architecture that learns to compress and reconstruct massive MIMO channel state information, significantly outperforming compressive sensing methods.

- **ISTA-Net: Interpretable Optimization-Inspired Deep Network for Image Compressive Sensing** — CVPR 2018 [`Algorithm Unrolling`] [`Compressed Sensing`]
  [[Paper](https://openaccess.thecvf.com/content_cvpr_2018/html/Zhang_ISTA-Net_Interpretable_Optimization-Inspired_CVPR_2018_paper.html)] [[Code](https://github.com/jianzhangcs/ISTA-Net-PyTorch)]
  Unrolled ISTA into a deep network with learned nonlinear transforms for proximal mapping, achieving fast and interpretable compressive sensing image reconstruction.

- **Deep Complex Networks** — ICLR 2018 [`Complex-Valued`]
  [[Paper](https://arxiv.org/abs/1705.09792)] [[Code](https://github.com/ChihebTrabelsi/deep_complex_networks)]
  Provided key building blocks for complex-valued deep networks including complex convolutions, complex batch normalization, and complex weight initialization, with state-of-the-art results on music transcription and speech.

- **EEGNet: A Compact Convolutional Neural Network for EEG-Based Brain-Computer Interfaces** — Journal of Neural Engineering 2018 [`Biomedical`]
  [[Paper](https://arxiv.org/abs/1611.08024)] [[Code](https://github.com/vlawhern/arl-eegmodels)]
  Introduced a compact CNN using depthwise and separable convolutions for EEG-based BCI, generalizing across P300, ERN, MRCP, and SMR paradigms with an order of magnitude fewer parameters.
