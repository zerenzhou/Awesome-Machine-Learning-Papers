# Computer Vision — 2019

- **EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks** — ICML 2019 [`CNN`]
  [[Paper](https://arxiv.org/abs/1905.11946)] [[Code](https://github.com/tensorflow/tpu/tree/master/models/official/efficientnet)]
  Proposed compound scaling of depth, width, and resolution with neural architecture search, achieving state-of-the-art accuracy-efficiency trade-offs.

- **A Style-Based Generator Architecture for Generative Adversarial Networks** — CVPR 2019 [`GAN`] [`Generation`]
  [[Paper](https://arxiv.org/abs/1812.04948)] [[Code](https://github.com/NVlabs/stylegan)]
  Introduced StyleGAN with style-based generator using adaptive instance normalization, enabling unprecedented control over image synthesis at multiple scales.

- **FCOS: Fully Convolutional One-Stage Object Detection** — ICCV 2019 [`Detection`]
  [[Paper](https://arxiv.org/abs/1904.01355)] [[Code](https://github.com/tianzhi0549/FCOS)]
  Proposed per-pixel prediction for anchor-free detection with centerness scoring, simplifying the detection pipeline while achieving competitive accuracy.

- **Large Scale GAN Training for High Fidelity Natural Image Synthesis** — ICLR 2019 [`GAN`] [`Generation`]
  [[Paper](https://arxiv.org/abs/1809.11096)] [[Code](https://github.com/ajbrock/BigGAN-PyTorch)]
  Scaled GANs to unprecedented model size and batch size (BigGAN), demonstrating that larger models with class-conditional generation dramatically improve image fidelity.
