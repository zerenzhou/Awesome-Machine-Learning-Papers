# Computer Vision — 2017

- **Feature Pyramid Networks for Object Detection** — CVPR 2017 [`Detection`] [`CNN`]
  [[Paper](https://arxiv.org/abs/1612.03144)]
  Built a top-down feature pyramid with lateral connections for multi-scale object detection, becoming a standard component in modern detectors.

- **Densely Connected Convolutional Networks** — CVPR 2017 [`CNN`]
  [[Paper](https://arxiv.org/abs/1608.06993)] [[Code](https://github.com/liuzhuang13/DenseNet)]
  Connected each layer to every subsequent layer for maximum feature reuse, improving parameter efficiency and gradient flow in deep networks.

- **Image-to-Image Translation with Conditional Adversarial Networks** — CVPR 2017 [`GAN`] [`Generation`]
  [[Paper](https://arxiv.org/abs/1611.10012)] [[Code](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix)]
  Proposed Pix2Pix, a general-purpose framework for paired image-to-image translation using conditional GANs.

- **Unpaired Image-to-Image Translation using Cycle-Consistent Adversarial Networks** — ICCV 2017 [`GAN`] [`Generation`]
  [[Paper](https://arxiv.org/abs/1703.10593)] [[Code](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix)]
  Introduced CycleGAN with cycle consistency loss for unpaired image translation, enabling style transfer without paired training data.

- **Mask R-CNN** — ICCV 2017 [`Detection`] [`Segmentation`]
  [[Paper](https://arxiv.org/abs/1703.06870)] [[Code](https://github.com/matterport/Mask_RCNN)]
  Extended Faster R-CNN with a parallel mask branch for simultaneous object detection and instance segmentation.

- **Deformable Convolutional Networks** — ICCV 2017 [`CNN`] [`Detection`]
  [[Paper](https://arxiv.org/abs/1703.06211)] [[Code](https://github.com/msracver/Deformable-ConvNets)]
  Introduced learnable offsets to convolutional sampling locations, enabling adaptive geometric transformation modeling for dense prediction tasks.
