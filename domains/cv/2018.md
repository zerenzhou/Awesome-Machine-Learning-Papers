# Computer Vision — 2018

- **Non-local Neural Networks** — CVPR 2018 [`CNN`] [`Attention`]
  [[Paper](https://arxiv.org/abs/1711.07971)] [[Code](https://github.com/facebookresearch/video-nonlocal-net)]
  Proposed non-local operations to capture long-range dependencies in a single layer, foreshadowing self-attention mechanisms in vision.

- **Squeeze-and-Excitation Networks** — CVPR 2018 [`CNN`]
  [[Paper](https://arxiv.org/abs/1709.01507)] [[Code](https://github.com/hujie-frank/SENet)]
  Introduced channel attention via squeeze-and-excitation blocks, winning ILSVRC 2017 by adaptively recalibrating channel-wise feature responses.

- **Progressive Growing of GANs for Improved Quality, Stability, and Variation** — ICLR 2018 [`GAN`] [`Generation`]
  [[Paper](https://arxiv.org/abs/1710.10196)] [[Code](https://github.com/tkarras/progressive_growing_of_gans)]
  Grew both generator and discriminator progressively from low to high resolution, enabling stable training of GANs up to 1024×1024.

- **MobileNetV2: Inverted Residuals and Linear Bottlenecks** — CVPR 2018 [`CNN`] [`Efficient`]
  [[Paper](https://arxiv.org/abs/1801.04381)]
  Proposed inverted residual blocks with linear bottlenecks for efficient mobile inference, becoming a standard backbone for on-device vision.

- **YOLOv3: An Incremental Improvement** — arXiv 2018 [`Detection`]
  [[Paper](https://arxiv.org/abs/1804.02767)] [[Code](https://github.com/pjreddie/darknet)]
  Introduced multi-scale predictions using a feature pyramid and the deeper Darknet-53 backbone, making YOLO competitive with two-stage detectors.

- **CornerNet: Detecting Objects as Paired Keypoints** — ECCV 2018 [`Detection`]
  [[Paper](https://arxiv.org/abs/1808.01244)] [[Code](https://github.com/princeton-vl/CornerNet)]
  Detected objects as pairs of top-left and bottom-right corner keypoints, pioneering anchor-free detection without predefined bounding boxes.
