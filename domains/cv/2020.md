# Computer Vision — 2020

- **Denoising Diffusion Probabilistic Models** — NeurIPS 2020 [`Diffusion`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2006.11239)] [[Code](https://github.com/hojonathanho/diffusion)]
  Demonstrated that diffusion models can generate high-quality images rivaling GANs, establishing the denoising diffusion framework as a practical generative paradigm.

- **End-to-End Object Detection with Transformers** — ECCV 2020 [`Detection`] [`Transformer`]
  [[Paper](https://arxiv.org/abs/2005.12872)] [[Code](https://github.com/facebookresearch/detr)]
  Introduced DETR, reformulating object detection as a set prediction problem with Transformer encoder-decoder and bipartite matching, eliminating anchors and NMS.

- **NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis** — ECCV 2020 [`3D`] [`Neural Rendering`]
  [[Paper](https://arxiv.org/abs/2003.08934)] [[Code](https://github.com/bmild/nerf)]
  Represented scenes as continuous 5D neural radiance fields for photorealistic novel view synthesis, launching the neural rendering revolution.

- **A Simple Framework for Contrastive Learning of Visual Representations** — ICML 2020 [`Self-Supervised`]
  [[Paper](https://arxiv.org/abs/2002.05709)] [[Code](https://github.com/google-research/simclr)]
  Proposed SimCLR, showing that simple contrastive learning with data augmentation, large batches, and a projection head achieves strong visual representations.

- **Bootstrap Your Own Latent: A New Approach to Self-Supervised Learning** — NeurIPS 2020 [`Self-Supervised`]
  [[Paper](https://arxiv.org/abs/2006.07733)]
  Introduced BYOL, learning visual representations without negative pairs via a momentum-updated target network, challenging the necessity of contrastive negatives.

- **EfficientDet: Scalable and Efficient Object Detection** — CVPR 2020 [`Detection`] [`Efficient`]
  [[Paper](https://arxiv.org/abs/1911.09070)] [[Code](https://github.com/google/automl/tree/master/efficientdet)]
  Proposed BiFPN for multi-scale feature fusion and compound scaling for detectors, achieving state-of-the-art accuracy-efficiency trade-offs.
