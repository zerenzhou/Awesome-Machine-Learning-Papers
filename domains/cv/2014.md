# Computer Vision — 2014

- **Rich Feature Hierarchies for Accurate Object Detection and Semantic Segmentation** — CVPR 2014 [`Detection`] [`CNN`]
  [[Paper](https://arxiv.org/abs/1311.2524)]
  Introduced R-CNN, combining selective search proposals with CNN features for object detection, establishing the region-based detection paradigm.

- **Spatial Pyramid Pooling in Deep Convolutional Networks for Visual Recognition** — ECCV 2014 [`Detection`] [`CNN`]
  [[Paper](https://arxiv.org/abs/1406.4729)]
  Introduced spatial pyramid pooling to handle arbitrary input sizes, enabling multi-scale feature extraction and faster region-based detection.
