# Computer Vision — 2024

- **SAM 2: Segment Anything in Images and Videos** — ArXiv 2024 [`Foundation Model`] [`Segmentation`]
  [[Paper](https://arxiv.org/abs/2408.00714)] [[Code](https://github.com/facebookresearch/sam2)]
  Extended Segment Anything to video with a streaming memory architecture for real-time promptable segmentation across frames.

- **Florence-2: Advancing a Unified Representation for a Variety of Vision Tasks** — CVPR 2024 [`Foundation Model`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2311.06242)] [[Code](https://huggingface.co/microsoft/Florence-2-large)]
  Proposed a sequence-to-sequence vision foundation model handling captioning, detection, and segmentation through unified text output.

- **Vision Mamba: Efficient Visual Representation Learning with Bidirectional State Space Model** — ICML 2024 [`SSM`] [`ViT`]
  [[Paper](https://arxiv.org/abs/2401.09417)] [[Code](https://github.com/hustvl/Vim)]
  Applied bidirectional Mamba state space models to vision, achieving competitive accuracy with linear-complexity token mixing.

- **VMamba: Visual State Space Model** — NeurIPS 2024 [`SSM`] [`ViT`]
  [[Paper](https://arxiv.org/abs/2401.10166)] [[Code](https://github.com/MzeroMiko/VMamba)]
  Introduced Cross-Scan Module for 2D-aware selective scanning, enabling state space models to capture spatial relationships in images.

- **Scaling Rectified Flow Transformers for High-Resolution Image Synthesis** — ICML 2024 [`Diffusion`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2403.03206)] [[Code](https://github.com/Stability-AI/sd3-ref)]
  Proposed the Stable Diffusion 3 architecture using rectified flow matching and a multimodal DiT backbone for high-fidelity image synthesis.

- **DALL-E 3** — ArXiv 2023 [`Diffusion`] [`Generation`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2309.17400)]
  Improved text-to-image generation by training on highly descriptive synthetic captions, greatly enhancing prompt adherence.

- **EfficientViT: Lightweight Multi-Scale Attention for High-Resolution Dense Prediction** — ICCV 2023 [`ViT`] [`Efficient`]
  [[Paper](https://arxiv.org/abs/2205.14756)] [[Code](https://github.com/mit-han-lab/efficientvit)]
  Designed a lightweight multi-scale linear attention module enabling efficient vision transformers for high-resolution dense prediction.

- **Grounded SAM: Assembling Open-World Models for Diverse Visual Tasks** — ArXiv 2024 [`Segmentation`] [`Detection`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2401.14159)] [[Code](https://github.com/IDEA-Research/Grounded-SAM-2)]
  Combined Grounding DINO with SAM 2 for open-set detection and segmentation driven by text, enabling flexible visual grounding.

- **FastViT: A Fast Hybrid Vision Transformer using Structural Reparameterization** — ICCV 2023 [`ViT`] [`Efficient`]
  [[Paper](https://arxiv.org/abs/2303.14189)] [[Code](https://github.com/apple/ml-fastvit)]
  Proposed RepMixer token mixing with structural reparameterization, achieving state-of-the-art latency-accuracy trade-offs on mobile devices.

- **Depth Anything: Unleashing the Power of Large-Scale Unlabeled Data** — CVPR 2024 [`Foundation Model`] [`Depth Estimation`]
  [[Paper](https://arxiv.org/abs/2401.10891)] [[Code](https://github.com/LiheYoung/Depth-Anything)]
  Trained a monocular depth foundation model by leveraging large-scale unlabeled images with a self-teaching strategy.
