# Computer Vision — 2024

- **SDXL: Improving Latent Diffusion Models for High-Resolution Image Synthesis** — ICLR 2024 [`Diffusion`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2307.01952)] [[Code](https://github.com/Stability-AI/generative-models)]
  Scaled up latent diffusion with a larger UNet, refiner model, and conditioning schemes to significantly improve open-source image generation quality.

- **Scaling Rectified Flow Transformers for High-Resolution Image Synthesis** — ICML 2024 [`Diffusion`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2403.03206)] [[Code](https://github.com/Stability-AI/sd3-ref)]
  Proposed the Stable Diffusion 3 architecture using rectified flow matching and a multimodal DiT backbone for high-fidelity image synthesis.

- **Florence-2: Advancing a Unified Representation for a Variety of Vision Tasks** — CVPR 2024 [`Foundation Model`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2311.06242)] [[Code](https://huggingface.co/microsoft/Florence-2-large)]
  Proposed a sequence-to-sequence vision foundation model handling captioning, detection, and segmentation through unified text output.

- **InternVL: Scaling up Vision Foundation Models and Aligning for Generic Visual-Linguistic Tasks** — CVPR 2024 Oral [`Foundation Model`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2312.14238)] [[Code](https://github.com/OpenGVLab/InternVL)]
  Scaled vision-language foundation models to 6B vision parameters with progressive alignment, achieving strong performance across diverse visual-linguistic benchmarks.

- **Vision Mamba: Efficient Visual Representation Learning with Bidirectional State Space Model** — ICML 2024 [`SSM`]
  [[Paper](https://arxiv.org/abs/2401.09417)] [[Code](https://github.com/hustvl/Vim)]
  Applied bidirectional Mamba state space models to vision, achieving competitive accuracy with linear-complexity token mixing.

- **VMamba: Visual State Space Model** — NeurIPS 2024 [`SSM`]
  [[Paper](https://arxiv.org/abs/2401.10166)] [[Code](https://github.com/MzeroMiko/VMamba)]
  Introduced Cross-Scan Module for 2D-aware selective scanning, enabling state space models to capture spatial relationships in images.

- **Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection** — ECCV 2024 [`Detection`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2303.05499)] [[Code](https://github.com/IDEA-Research/GroundingDINO)]
  Combined a DINO-based detector with grounded pre-training for strong open-set object detection from text prompts.

- **Grounded SAM: Assembling Open-World Models for Diverse Visual Tasks** — arXiv 2024 [`Segmentation`] [`Detection`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2401.14159)] [[Code](https://github.com/IDEA-Research/Grounded-SAM-2)]
  Combined Grounding DINO with SAM for open-set detection and segmentation driven by text, enabling flexible visual grounding.

- **Depth Anything: Unleashing the Power of Large-Scale Unlabeled Data** — CVPR 2024 [`Foundation Model`] [`Depth Estimation`]
  [[Paper](https://arxiv.org/abs/2401.10891)] [[Code](https://github.com/LiheYoung/Depth-Anything)]
  Trained a monocular depth foundation model by leveraging large-scale unlabeled images with a self-teaching strategy.

- **Depth Anything V2: A More Capable Foundation Model for Monocular Depth Estimation** — NeurIPS 2024 [`Foundation Model`] [`Depth Estimation`]
  [[Paper](https://arxiv.org/abs/2406.09414)] [[Code](https://github.com/DepthAnything/Depth-Anything-V2)]
  Improved monocular depth estimation using synthetic data and large teacher models for finer details and robustness.

- **YOLO-World: Real-Time Open-Vocabulary Object Detection** — CVPR 2024 [`Detection`] [`Vision-Language`]
  [[Paper](https://arxiv.org/abs/2401.17270)] [[Code](https://github.com/AILab-CVC/YOLO-World)]
  Extended YOLO to open-vocabulary detection with vision-language pretraining, enabling real-time detection of arbitrary categories from text descriptions.

- **DETRs Beat YOLOs on Real-time Object Detection** — CVPR 2024 [`Detection`] [`Transformer`]
  [[Paper](https://arxiv.org/abs/2304.08069)] [[Code](https://github.com/lyuwenyu/RT-DETR)]
  Proposed RT-DETR, the first real-time DETR-based detector outperforming YOLO variants via efficient hybrid encoder design.

- **PixArt-α: Fast Training of Diffusion Transformer for Photorealistic Text-to-Image Synthesis** — ICLR 2024 Spotlight [`Diffusion`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2310.00426)] [[Code](https://github.com/PixArt-alpha/PixArt-alpha)]
  Achieved DALL-E 2 quality with 10% training cost via a decomposed DiT training strategy with cross-attention for text conditioning.

- **YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information** — ECCV 2024 [`Detection`]
  [[Paper](https://arxiv.org/abs/2402.13616)] [[Code](https://github.com/WongKinYiu/yolov9)]
  Introduced Programmable Gradient Information and GELAN backbone to prevent information loss in deep networks, setting new YOLO detection records.

- **YOLOv10: Real-Time End-to-End Object Detection** — NeurIPS 2024 [`Detection`]
  [[Paper](https://arxiv.org/abs/2405.14458)] [[Code](https://github.com/THU-MIG/yolov10)]
  Eliminated NMS post-processing with consistent dual assignments, achieving end-to-end real-time detection with state-of-the-art accuracy-latency trade-offs.

- **DreamGaussian: Generative Gaussian Splatting for Efficient 3D Content Creation** — ICLR 2024 Oral [`3D`] [`Generation`]
  [[Paper](https://arxiv.org/abs/2309.16653)] [[Code](https://github.com/dreamgaussian/dreamgaussian)]
  Combined Gaussian Splatting with generative 3D priors for single-image 3D content creation in ~2 minutes with mesh extraction and texture refinement.

- **4D Gaussian Splatting for Real-Time Dynamic Scene Rendering** — CVPR 2024 [`3D`] [`Rendering`]
  [[Paper](https://arxiv.org/abs/2310.08528)] [[Code](https://github.com/hustvl/4DGaussians)]
  Extended 3D Gaussian Splatting to dynamic scenes with a deformation field for real-time rendering of time-varying content.

- **Sapiens: Foundation for Human Vision Models** — ECCV 2024 [`Foundation Model`] [`Human`]
  [[Paper](https://arxiv.org/abs/2408.12569)] [[Code](https://github.com/facebookresearch/sapiens)]
  Pre-trained 0.3B–2B parameter models on 300M human images for pose estimation, body-part segmentation, depth, and surface normals at 1K resolution.

- **VideoMamba: State Space Model for Efficient Video Understanding** — ECCV 2024 [`SSM`] [`Video`]
  [[Paper](https://arxiv.org/abs/2403.06977)] [[Code](https://github.com/OpenGVLab/VideoMamba)]
  Adapted Mamba's linear-complexity SSM to video via bidirectional spatiotemporal scanning, achieving 6× speedup over transformer baselines on long videos.
