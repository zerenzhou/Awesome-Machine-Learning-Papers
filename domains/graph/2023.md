# Graph Learning — 2023

- **GPS: Recipe for a General, Powerful, Scalable Graph Transformer** — ICML 2023 [`Graph Transformer`]
  [[Paper](https://arxiv.org/abs/2205.12454)] [[Code](https://github.com/rampasek/GraphGPS)]
  Proposed a modular Graph Transformer framework combining MPNN local message passing with global attention for scalable and expressive graph learning.

- **Exphormer: Sparse Transformers for Graphs** — ICML 2023 [`Graph Transformer`]
  [[Paper](https://arxiv.org/abs/2303.06147)] [[Code](https://github.com/hamed1375/Exphormer)]
  Introduced sparse attention mechanisms based on expander graphs and virtual nodes for efficient Graph Transformers with linear complexity.

- **GraphMAE2: A Decoding-Enhanced Masked Self-Supervised Graph Learner** — WWW 2023 [`Foundation Model`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2304.04779)] [[Code](https://github.com/THUDM/GraphMAE2)]
  Extended masked graph autoencoders with multi-view random re-masking decoding to learn more robust graph representations.

- **PRODIGY: Enabling In-context Learning Over Graphs** — NeurIPS 2023 [`Foundation Model`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2305.12600)] [[Code](https://github.com/snap-stanford/prodigy)]
  Presented a pretraining framework that enables in-context learning on graphs via prompt graphs without task-specific fine-tuning.

- **GraphGPT: Graph Instruction Tuning for Large Language Models** — SIGIR 2024 [`LLM`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2310.13023)] [[Code](https://github.com/HKUDS/GraphGPT)]
  Aligned graph structural knowledge with LLMs through graph instruction tuning, enabling text-based reasoning over graph-structured data.

- **DiGress: Discrete Denoising Diffusion for Graph Generation** — ICLR 2023 [`Generation`]
  [[Paper](https://arxiv.org/abs/2209.14734)] [[Code](https://github.com/cvignac/DiGress)]
  Applied discrete diffusion processes to jointly generate graph nodes and edges, achieving strong results on molecular and general graph generation.

- **Weisfeiler and Leman Go Relational** — LOG 2023 [`Theory`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2211.17113)]
  Extended the WL hierarchy to relational structures, analyzing the expressive power of GNNs on relational and knowledge graphs.

- **DrugCLIP: Contrastive Protein-Molecule Representation Learning for Virtual Screening** — NeurIPS 2023 [`Molecular`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2310.06367)]
  Proposed a contrastive learning framework that aligns protein and molecular graph representations for zero-shot virtual drug screening.
