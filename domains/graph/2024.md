# Graph Learning — 2024

- **One for All: Towards Training One Graph Model for All Classification Tasks** — ICLR 2024 [`Foundation Model`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2310.00149)] [[Code](https://github.com/LechengKong/OneForAll)]
  Proposed a single graph model that handles node, edge, and graph classification across diverse domains using text-attributed graphs and a unified prompting mechanism.

- **LLaGA: Large Language and Graph Assistant** — ICML 2024 [`LLM`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2402.08170)] [[Code](https://github.com/VITA-Group/LLaGA)]
  Reorganized graph nodes into structure-aware sequences to integrate graph reasoning into large language models without modifying LLM parameters.

- **InstructGraph: Boosting Large Language Models via Graph-centric Instruction Tuning and Preference Alignment** — ACL 2024 [`LLM`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2402.08785)] [[Code](https://github.com/wjn1996/InstructGraph)]
  Instruction-tuned LLMs with graph-centric tasks using a structured graph language to enable unified graph understanding and generation.

- **GraphAny: A Foundation Model for Node Classification on Any Graph** — ICML 2024 [`Foundation Model`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2405.20445)] [[Code](https://github.com/DeepGraphLearning/GraphAny)]
  Designed an inference-time foundation model for node classification that generalizes to unseen graphs by aggregating outputs from multiple analytical baselines via learned attention.

- **GraphTranslator: Aligning Graph Model to Large Language Model for Open-ended Tasks** — WWW 2024 [`LLM`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2402.07197)]
  Proposed a Translator module to align pre-trained GNN representations with LLM token spaces, enabling open-ended graph reasoning through natural language.

- **MoleculeSTM: Multi-modal Molecule Structure-Text Model for Text-Based Retrieval and Editing** — Nature Machine Intelligence 2024 [`Molecular`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2212.10789)] [[Code](https://github.com/chao1224/MoleculeSTM)]
  Jointly learned molecular graph and text representations via contrastive learning, enabling text-guided molecular retrieval and editing.

- **Towards Foundation Models for Knowledge Graph Reasoning** — ICLR 2024 [`Foundation Model`] [`GNN`]
  [[Paper](https://arxiv.org/abs/2310.04562)] [[Code](https://github.com/DeepGraphLearning/ULTRA)]
  Presented ULTRA, a foundation model for knowledge graph reasoning that generalizes to any unseen knowledge graph at inference time using relative relation representations.
