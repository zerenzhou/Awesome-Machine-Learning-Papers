# 2022 — Generative Recommendation Papers

2022 establishes the generative recommendation paradigm: DSI (in classic.md) seeds the idea from IR, and early rec-specific explorations apply seq2seq generation to produce item identifiers directly. The focus is on item representation design — what identifier to generate.

## Generative Retrieval Foundations

### Generative Recommended Model with Token-Level and Sequence-Level Knowledge Transfer (GenRec)
- **Authors:** Ji et al.
- **Venue:** (search: GenRec generative recommendation token sequence knowledge transfer 2022)
- **Paper:** (search: generative recommendation token sequence knowledge transfer 2022)
- **Summary:** Early generative recommendation work applying T5-style seq2seq generation to produce item token sequences representing items, exploring token-level and sequence-level transfer from pre-trained LMs to generative recommendation objectives.
- **Tags:** `#generative` `#seq2seq` `#token` `#transfer`

### Generative Retrieval for Long Documents
- **Authors:** Bevilacqua et al.
- **Venue:** arXiv 2022
- **Paper:** [arXiv](https://arxiv.org/abs/2204.13558)
- **Summary:** MINDER extends DSI from document-level to passage-level identifiers, directly inspiring multi-granularity ID designs in TIGER and subsequent generative recommenders; shows that multi-token ID generation enables finer semantic discrimination.
- **Tags:** `#generative-retrieval` `#multi-token` `#ir`

## Item Tokenization / Semantic ID Design

### Learning Vector Quantization for Recommendation
- **Authors:** (search: VQ-Rec vector quantization recommendation item ID 2022)
- **Paper:** (search: vector quantization recommendation discrete item representation 2022)
- **Summary:** Applies vector quantization to learn discrete item codes from item content features, creating a structured semantic ID space suitable for autoregressive generation in generative recommendation settings.
- **Tags:** `#vector-quantization` `#semantic-id` `#discrete-representation`

## Sequential Generative Models

### GPT4Rec: A Generative Framework for Personalized Recommendation and User Interests Interpretation
- **Authors:** Li et al.
- **Venue:** arXiv 2023 (developed 2022)
- **Paper:** [arXiv](https://arxiv.org/abs/2304.03879)
- **Summary:** Frames sequential recommendation as language model generation where user history is formatted as natural language and the model generates item titles; uses beam search to retrieve multiple items and interprets user interests via natural language generation.
- **Tags:** `#gpt4rec` `#generative` `#sequential` `#beam-search`

## Foundation-model Rec

### Pre-training Methods in Information Retrieval
- **Authors:** Fan et al.
- **Venue:** FnTIR 2022
- **Paper:** (search: pre-training methods information retrieval survey Fan 2022)
- **Summary:** Survey of pre-training in IR including generative retrieval, directly informing design choices for generative recommendation; covers docid formats, seq2seq architectures, and training objectives that later appear in TIGER and related works.
- **Tags:** `#survey` `#pre-training` `#generative-retrieval` `#ir`
