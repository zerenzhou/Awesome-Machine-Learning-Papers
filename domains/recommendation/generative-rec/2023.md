# 2023 — Generative Recommendation Papers

2023 is the breakthrough year: TIGER (classic.md) proves end-to-end RQ-VAE-based generative rec works; LC-Rec shows language-item code alignment enables zero-shot transfer; and IDGenRec demonstrates that LLM-native item IDs outperform discrete codes for language-based generation.

## Semantic ID Approaches

### Recommender Systems with Generative Retrieval (TIGER)
- **Authors:** Rajput et al.
- **Venue:** NeurIPS 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2305.05065)
- **Summary:** (Also in classic.md — core 2023 result.) TIGER assigns hierarchical RQ-VAE codes to items and generates item ID sequences autoregressively via T5; the first end-to-end generative recommender competitive with retrieval + reranking pipelines on standard benchmarks.
- **Tags:** `#tiger` `#rqvae` `#semantic-id` `#seminal`

### IDGenRec: LLM-RecSys Alignment with Textual ID Learning for Generative Recommendation
- **Authors:** Tan et al.
- **Venue:** SIGIR 2024
- **Paper:** [arXiv](https://arxiv.org/abs/2403.19021)
- **Summary:** Learns a textual ID for each item by prompting an LLM to generate a compact, unique descriptive identifier; the model then fine-tunes to generate these IDs, achieving better semantic consistency between item IDs and LLM token vocabulary than RQ-VAE codes.
- **Tags:** `#idgenrec` `#textual-id` `#llm` `#alignment`

## Language-code Alignment

### LC-Rec: Aligning Large Language Models with Sequential Recommendation via Longitudinal Data
- **Authors:** Zheng et al.
- **Venue:** SIGIR 2024
- **Paper:** [arXiv](https://arxiv.org/abs/2405.00988)
- **Code:** [GitHub](https://github.com/zhengbw0324/LC-Rec)
- **Summary:** Aligns language code space with item ID space via a hierarchical code-item contrastive objective, enabling LLM to generate structurally consistent item codes while retaining semantic item meaning from text descriptions; achieves zero-shot cross-domain transfer.
- **Tags:** `#lc-rec` `#alignment` `#language-code` `#cross-domain`

## Large-scale Generative Rec

### HSTU: Actions Speak Louder than Words: Trillion-Parameter Sequential Transducers for Generative Recommendations
- **Authors:** Zhai et al.
- **Venue:** ICML 2024
- **Paper:** [arXiv](https://arxiv.org/abs/2402.17152)
- **Summary:** (Also in classic.md.) Meta's industrial generative rec architecture using Hierarchical Sequential Transducers (HSTU) that process user action sequences as multi-granularity tokens; demonstrates Transformer-like scaling laws on trillion-scale recommendation data.
- **Tags:** `#hstu` `#scaling` `#industrial` `#meta`

## Diffusion-based Generative Rec

### Collaborative Filtering as Denoising (DiffCF)
- **Authors:** (search: DiffCF collaborative filtering denoising diffusion recommendation 2023)
- **Paper:** (search: diffusion collaborative filtering recommendation denoising 2023)
- **Summary:** Frames the item preference learning problem as a conditional denoising process over item latent spaces, training a diffusion model conditioned on user history to generate preference distributions; complements RQ-VAE-based approaches with continuous generative objectives.
- **Tags:** `#diffusion` `#cf` `#generative`
