# 2023 — Debiasing / Fairness / Causal Recommendation Papers

2023 sees causal recommendation branch into three mature directions: LLM-augmented causal re-ranking (MELT), invariant causal CF for popularity debiasing (InvCF/CausCF), and a comprehensive survey formalizing the field. Debiasing methods increasingly target real production systems rather than academic datasets.

## Popularity Debiasing via Causal CF

### InvCF: Invariant Causal Collaborative Filtering for Popularity Bias Debiasing
- **Authors:** (search: InvCF invariant causal collaborative filtering popularity bias 2023)
- **Paper:** (search: invariant causal collaborative filtering debiasing 2023 SIGIR WWW KDD)
- **Summary:** Constructs multiple "environments" from interaction data split by item popularity quintiles and applies IRM across environments, forcing CF representations to capture causally stable user preference signals rather than popularity-correlated shortcuts; achieves strong performance on tail items without degrading head-item recommendations.
- **Tags:** `#invcf` `#irm` `#causal` `#popularity-bias` `#cf`

### CausalCF: Causal Collaborative Filtering with Cold-Start Awareness
- **Authors:** (search: CausalCF causal collaborative filtering cold-start 2023)
- **Paper:** (search: causal collaborative filtering cold-start counterfactual 2023)
- **Summary:** Distinguishes causal user preferences from spurious co-interaction patterns by constructing counterfactual training pairs via do-calculus interventions, with an additional cold-start transfer head that maps new item content features into the debiased CF embedding space.
- **Tags:** `#causalcf` `#causal` `#cold-start` `#counterfactual`

## LLM-enhanced Debiasing

### MELT: Mutual Enhancement of Long-Tailed User and Item for Sequential Recommendation
- **Authors:** (search: MELT mutual enhancement long-tailed sequential recommendation 2023)
- **Paper:** (search: MELT long-tail user item recommendation 2023 SIGIR KDD)
- **Summary:** Addresses joint long-tail user and item bias in sequential rec via a mutual-enhancement training strategy: a frequency-balanced sampler and a LLM-generated description augmentation for tail items collaboratively improve representation quality for both rare users and rare items.
- **Tags:** `#melt` `#long-tail` `#fairness` `#llm` `#sequential`
