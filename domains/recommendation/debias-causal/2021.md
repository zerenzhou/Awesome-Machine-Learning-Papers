# 2021 — Debiasing / Fairness / Causal Recommendation Papers

2021 is the peak year for causal recommendation: DICE disentangles interest from conformity in user interactions, MACR and PDA mature causal graph debiasing, and AutoDebias uses meta-learning for automatic propensity estimation. Counterfactual data augmentation also emerges for data-efficient debiasing.

## Causal Disentanglement

### Disentangling User Interest and Conformity for Recommendation with Causal Embedding (DICE)
- **Authors:** Zheng et al.
- **Venue:** WWW 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2006.11011)
- **Code:** [GitHub](https://github.com/tsinghua-fib-lab/DICE)
- **Summary:** Separates user interaction signals into interest-driven (genuine preference) and conformity-driven (social/popularity pressure) components using independent embedding spaces optimized with causal-effect constraints; interest embeddings are used at inference to avoid conformity bias.
- **Tags:** `#dice` `#disentanglement` `#conformity` `#causal`

## Automatic Debiasing

### AutoDebias: Learning to Debias for Recommendation
- **Authors:** Chen et al.
- **Venue:** SIGIR 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2105.04170)
- **Code:** [GitHub](https://github.com/DongHande/AutoDebias)
- **Summary:** Treats propensity score estimation and debiasing hyperparameter selection as a bi-level meta-learning problem; using a small unbiased uniform-data validation set to guide outer optimization of debiasing parameters while the inner loop trains the recommender.
- **Tags:** `#autodebias` `#meta-learning` `#propensity` `#bilevel`

## Counterfactual Data Augmentation

### CR: Causal Recommendation via Counterfactual Augmentation
- **Authors:** (search: CR causal recommendation counterfactual augmentation 2021)
- **Paper:** (search: counterfactual data augmentation causal recommendation 2021)
- **Summary:** Generates counterfactual user-item interaction samples by intervening on item popularity while holding user preference fixed, using these augmented samples to train recommendation models robust to popularity-induced co-occurrence bias.
- **Tags:** `#counterfactual` `#data-augmentation` `#popularity-bias`

## Knowledge Distillation for Debiasing

### KDCRec: Knowledge Distillation for Counterfactual Recommendation via Uniform Data
- **Authors:** (search: KDCRec knowledge distillation counterfactual recommendation uniform data 2021)
- **Paper:** (search: knowledge distillation debiasing recommendation uniform data 2021)
- **Summary:** Distills knowledge from a bias-free teacher model (trained on uniform random data) to a student model trained on biased interaction logs, bridging the gap between limited unbiased data and large biased datasets for debiasing.
- **Tags:** `#kdcrec` `#knowledge-distillation` `#uniform-data` `#debiasing`

## Invariant Risk Minimization

### Invariant Preference Learning for General Debiasing in Recommendation (InvRL)
- **Authors:** (search: InvRL invariant preference learning debiasing recommendation 2021)
- **Paper:** (search: invariant risk minimization debiasing recommendation 2021)
- **Summary:** Applies invariant risk minimization (IRM) to recommendation, learning user preference representations that are consistent across environments constructed from different bias conditions (popularity levels, display positions); invariant representations generalize better across bias shifts.
- **Tags:** `#irm` `#invariant-learning` `#debiasing`
