# 2022 — CTR Prediction & Ranking Papers

2022 sees TransAct (Twitter's Transformer-based action sequence model), DHEN's deep hierarchical ensemble, and growing interest in causal and contrastive debiasing for CTR. Multi-interest disentanglement and retrieval-ranking co-training emerge as industrial priorities.

## Industrial Transformer Architectures

### TransAct: Transformer-based Realtime User Action Model for Twitter's Recommendation System
- **Authors:** Xia et al.
- **Venue:** KDD 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2306.00248)
- **Summary:** Applies a Transformer directly to users' real-time action sequences (tweets interacted with) for Tweet recommendation ranking; replaces feature aggregation with full sequence encoding and achieves production gains by capturing nuanced temporal patterns in engagement.
- **Tags:** `#transact` `#transformer` `#real-time` `#twitter`

### DHEN: A Deep and Hierarchical Ensemble Network for Large-Scale Click-Through Rate Prediction
- **Authors:** Liu et al.
- **Venue:** DLP-KDD 2022
- **Paper:** [arXiv](https://arxiv.org/abs/2203.11014)
- **Summary:** Hierarchically ensembles multiple feature interaction modules (inner product, bilinear, attention, MLP) via learned gating, achieving state-of-the-art on industrial CTR benchmarks by automatically combining diverse interaction types without manual model selection.
- **Tags:** `#dhen` `#ensemble` `#feature-interaction` `#meta`

## Multi-interest Modeling

### Multi-Interest Network with Dynamic Routing for Recommendation at Tmall (MIND)
- **Authors:** Li et al.
- **Venue:** CIKM 2019 (widely benchmarked in 2022 multi-interest literature)
- **Paper:** [arXiv](https://arxiv.org/abs/1904.08030)
- **Summary:** Uses capsule routing to disentangle a user's multiple diverse interests into separate capsule vectors, enabling retrieval for diverse user personas simultaneously in Tmall's candidate generation stage.
- **Tags:** `#mind` `#multi-interest` `#capsule` `#alibaba`

### Controllable Multi-Interest Framework for Recommendation
- **Authors:** Cen et al.
- **Venue:** KDD 2020
- **Paper:** [arXiv](https://arxiv.org/abs/2005.09347)
- **Summary:** ComiRec extends multi-interest modeling with a controllable aggregation mechanism that adjusts diversity vs. accuracy trade-off at inference time, enabling intent-level retrieval with user-level controllability.
- **Tags:** `#comirec` `#multi-interest` `#diversity`

## Causal / Debiasing in CTR

### A Model-Agnostic Causal Learning Framework for Recommendation using Search Data
- **Authors:** Xu et al.
- **Venue:** WWW 2022
- **Paper:** (search: causal learning framework recommendation search data Xu WWW 2022)
- **Summary:** Uses search query logs as instrumental variables to identify causal user-item preferences in clicked recommendation data, deconfounding popularity and position bias without requiring randomized experiments.
- **Tags:** `#causal` `#debiasing` `#search` `#ctr`
