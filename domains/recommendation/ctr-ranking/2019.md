# 2019 — CTR Prediction & Ranking Papers

2019 is a landmark year for industrial CTR: DIEN adds gated recurrent interest evolution on top of DIN's attention, DSIN splits history into sessions, DLRM formalizes Meta's production architecture, and MIMN tackles long-term memory via external neural memory networks.

## User Interest Evolution

### Deep Interest Evolution Network for Click-Through Rate Prediction (DIEN)
- **Authors:** Zhou et al.
- **Venue:** AAAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1809.03672)
- **Code:** [GitHub](https://github.com/mouna99/dien)
- **Summary:** Adds a two-layer architecture on top of DIN: an interest extractor layer (GRU) captures behavioral evolution, and an interest evolving layer (AUGRU) uses attention scores to filter evolution relevant to the target item; achieves large CTR gains at Alibaba.
- **Tags:** `#dien` `#gru` `#interest-evolution` `#alibaba`

### Deep Session Interest Network for Click-Through Rate Prediction (DSIN)
- **Authors:** Feng et al.
- **Venue:** IJCAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1905.06482)
- **Summary:** Segments user behavior history into sessions and uses self-attention within each session plus an inter-session BiLSTM, capturing session-level intent patterns that DIN and DIEN miss; validated on Alibaba production data.
- **Tags:** `#dsin` `#session` `#interest-modeling` `#alibaba`

## Long-sequence Memory Modeling

### Practice on Long Sequential User Behavior Modeling for Click-Through Rate Prediction (MIMN)
- **Authors:** Pi et al.
- **Venue:** KDD 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1905.09433)
- **Summary:** Uses a Neural Turing Machine-style memory to encode user's lifetime behavior sequences (up to 1000 behaviors), maintaining a fixed-size memory that is updated incrementally, enabling long-term user interest modeling without linear inference cost.
- **Tags:** `#mimn` `#memory-network` `#long-sequence` `#alibaba`

## Industrial Architecture

### Deep Learning Recommendation Model for Personalization and Recommendation Systems (DLRM)
- **Authors:** Naumov et al.
- **Venue:** arXiv 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1906.00091)
- **Code:** [GitHub](https://github.com/facebookresearch/dlrm)
- **Summary:** Meta's production recommendation architecture combining bottom MLPs for dense features with embedding tables for sparse features, joined via dot-product interactions; released as an open-source benchmark that became the standard industry CTR reference architecture.
- **Tags:** `#dlrm` `#industrial` `#meta` `#benchmark`

## Multi-task Ranking

### Recommending What Video to Watch Next: A Multitask Ranking System
- **Authors:** Zhao et al.
- **Venue:** RecSys 2019
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3298689.3346997)
- **Summary:** YouTube's multi-task ranking system that jointly optimizes engagement and satisfaction objectives via multiple output heads, using a Mixture-of-Experts (MMoE) backbone and position bias correction through shallow tower training.
- **Tags:** `#multi-task` `#youtube` `#position-bias` `#industrial`

## Knowledge-based Feature Interaction

### Knowledge Graph Convolutional Networks for Recommender Systems (KGCN)
- **Authors:** Wang et al.
- **Venue:** WWW 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1904.12575)
- **Code:** [GitHub](https://github.com/hwwang55/KGCN)
- **Summary:** Propagates entity embeddings through knowledge graphs via relation-aware GCN aggregation, enriching item representations for CTR prediction tasks with knowledge-graph-derived semantic features.
- **Tags:** `#kgcn` `#knowledge-graph` `#ctr`
