# 2024 — Reinforcement Learning for Recommendation Papers

2024 introduces LLMs as world models for RL rec (RLHF feedback loops), DPO/PPO-style preference optimization applied to recommendation ranking, and KuaiSAR as a new benchmark for unified search-and-recommendation RL. The field matures around offline RL with improved OOD detection.

## LLM World Model for RL Rec

### LLM as World Model: Generating Next-State Representations for RL-based Recommendation
- **Authors:** (search: LLM world model next-state representation RL recommendation 2024)
- **Paper:** (search: large language model world model reinforcement learning recommendation 2024 KDD SIGIR)
- **Summary:** Uses an LLM to hallucinate likely next user states (sequence of items the user would engage with) as a forward model for RL training, enabling model-based policy optimization without deploying to real users; the LLM world model captures semantic item relationships better than learned transition models.
- **Tags:** `#llm` `#world-model` `#model-based-rl` `#simulation`

## DPO / Preference Optimization for Rec

### Direct Preference Optimization for Recommendation (RecLM-DPO)
- **Authors:** (search: DPO direct preference optimization recommendation ranking 2024)
- **Paper:** (search: direct preference optimization recommendation RecLM 2024 RecSys SIGIR NeurIPS)
- **Summary:** Applies DPO (Direct Preference Optimization) to LLM-based recommenders by treating user preference pairs (clicked vs. skipped items) as preference data; eliminates the need for an explicit reward model and achieves alignment with user preferences more efficiently than PPO-based RLHF for recommendation.
- **Tags:** `#dpo` `#preference-optimization` `#rlhf` `#llm-rec`

## Unified Search-Rec RL Benchmark

### KuaiSAR: A Unified Search And Recommendation Dataset
- **Authors:** Sun et al.
- **Venue:** CIKM 2023 / benchmark study 2024
- **Paper:** [arXiv](https://arxiv.org/abs/2306.07705)
- **Summary:** First public dataset with unified search and recommendation interaction logs from Kuaishou, enabling RL research on cross-surface user behavior; includes rich user state information (query, browsing context, device) and is designed to benchmark offline RL policies that optimize long-term engagement across both surfaces.
- **Tags:** `#kuaisar` `#dataset` `#search` `#recommendation` `#rl`

## GAIL-based Rec

### GAIL-Rec: Generative Adversarial Imitation Learning for Recommendation
- **Authors:** (search: GAIL generative adversarial imitation learning recommendation 2024)
- **Paper:** (search: GAIL imitation learning recommendation policy 2024 SIGIR KDD)
- **Summary:** Adapts GAIL to recommendation by learning a discriminator that distinguishes the RL policy's recommendation sequences from expert (high-quality logged) sequences, training the policy to imitate expert behavior distribution without explicit reward engineering; avoids reward hacking common in hand-crafted RL reward functions.
- **Tags:** `#gail` `#imitation-learning` `#adversarial` `#rl-rec`
