# 2019 — Reinforcement Learning for Recommendation Papers

2019 is the breakthrough year for RL-based recommendation: YouTube's REINFORCE-based approach (Top-K off-policy correction), SlateQ's decomposed Q-learning for slate actions, and hierarchical RL for multi-step session recommendation all appear simultaneously, establishing RL-rec as a practical paradigm.

## Policy Gradient (REINFORCE)

### Top-K Off-Policy Correction for a REINFORCE Recommender System
- **Authors:** Chen et al.
- **Venue:** WSDM 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1812.02353)
- **Summary:** Adapts REINFORCE for large-action-space recommendation with off-policy correction: importance weights from behavior vs. target policy correct for the distribution shift in logged data; the top-K correction extends the standard single-item objective to slate recommendation, deployed at YouTube.
- **Tags:** `#reinforce` `#off-policy` `#top-k` `#youtube` `#seminal`

### Generative Adversarial User Model for Reinforcement Learning Based Recommendation System
- **Authors:** Chen et al.
- **Venue:** ICML 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1812.10613)
- **Summary:** Trains a GAN-based user environment simulator that models user responses (clicks, skips) to simulate recommendation feedback without online A/B tests; the policy gradient agent is trained in the simulated environment, enabling safe offline RL for recommendation.
- **Tags:** `#gan` `#user-simulator` `#policy-gradient` `#offline-rl`

## Value-based / Slate RL

### SlateQ: A Tractable Decomposition for Reinforcement Learning with Recommendation Sets
- **Authors:** Ie et al.
- **Venue:** IJCAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1905.12767)
- **Summary:** Decomposes the Q-function of slate recommendation (combinatorial action space) into item-level Q-values under linear user choice models; enables tractable Q-learning over slates of items and was validated in YouTube's recommendation environment.
- **Tags:** `#slateq` `#q-learning` `#slate` `#value-based`

## Hierarchical RL

### HRL4Rec: Hierarchical Reinforcement Learning for Course Recommendation in MOOCs
- **Authors:** Zhang et al.
- **Venue:** AAAI 2020
- **Paper:** (search: HRL4Rec hierarchical reinforcement learning course recommendation MOOC AAAI 2020)
- **Summary:** Designs a two-level hierarchical policy: a high-level policy selects a topic/goal and a low-level policy selects specific items within that topic; enables long-horizon recommendation planning where item-level decisions serve macro learning or engagement goals.
- **Tags:** `#hrl` `#hierarchical` `#course-rec` `#mooc`

## Model-based RL / Simulation

### Virtual-Taobao: Virtualizing Real-world Online Retail Environment for Reinforcement Learning
- **Authors:** Shi et al.
- **Venue:** AAAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1805.10000)
- **Summary:** Builds a calibrated e-commerce simulation environment (Virtual Taobao) by training user behavior generative models and product feature models; enables offline RL policy training and evaluation without live system interaction, a blueprint for rec system simulation.
- **Tags:** `#simulation` `#taobao` `#environment-model` `#model-based-rl`
