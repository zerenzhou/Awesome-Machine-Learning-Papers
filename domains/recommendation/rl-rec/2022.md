# 2022 — Reinforcement Learning for Recommendation Papers

2022 advances multi-objective RL for recommendation, with M3Rec handling hierarchical multi-step decision making. Counterfactual RL and causal policy gradient methods also emerge, addressing the confounding issue in recommendation logs when learning policies offline.

## Hierarchical Multi-step RL

### M3Rec: A Multi-level Memory Management Framework for Long-term and Short-term User Interest Modeling in Recommendation
- **Authors:** (search: M3Rec multi-level memory management long-term short-term user interest recommendation RL 2022)
- **Paper:** (search: M3Rec hierarchical reinforcement learning recommendation memory 2022)
- **Summary:** Three-level hierarchical RL framework for recommendation: a high-level policy selects long-term interest goals, a mid-level policy manages session-level topic transitions, and a low-level policy selects individual items; achieves significantly better long-term retention than flat RL policies.
- **Tags:** `#m3rec` `#hierarchical-rl` `#multi-level` `#memory`

## Counterfactual / Causal Policy Gradient

### Counterfactual Data-Augmented Sequential Recommendation
- **Authors:** Wang et al.
- **Venue:** SIGIR 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2108.06678)
- **Summary:** Generates counterfactual user interaction sequences by applying do-calculus interventions on item popularity and position variables, augmenting sequential RL training with causally deconfounded experience; improves policy generalization under distribution shift.
- **Tags:** `#counterfactual` `#data-augmentation` `#causal` `#sequential-rl`

## Multi-objective Optimization

### PGPR: Policy-Guided Path Reasoning for Recommendation
- **Authors:** Xian et al.
- **Venue:** KDD 2019 (extended work influential in 2022 RL-rec)
- **Paper:** [arXiv](https://arxiv.org/abs/1906.05237)
- **Code:** [GitHub](https://github.com/orcax/PGPR)
- **Summary:** Uses a policy gradient agent to reason over knowledge graph paths from users to items, learning to follow multi-hop relational chains as an explainable recommendation policy; achieves strong accuracy with human-interpretable reasoning paths.
- **Tags:** `#pgpr` `#knowledge-graph` `#path-reasoning` `#explainability`

## User Simulator Improvements

### KuaiRec: A Fully-Observed Dataset for Recommender Systems
- **Authors:** Gao et al.
- **Venue:** CIKM 2022
- **Paper:** [arXiv](https://arxiv.org/abs/2202.10842)
- **Code:** [GitHub](https://github.com/chongminggao/KuaiRec)
- **Summary:** First fully-observed recommendation dataset (every user has watched every item) from Kuaishou, enabling exact offline evaluation of RL recommendation policies without exposure bias; provides a ground-truth environment for offline RL training and evaluation.
- **Tags:** `#kuairec` `#dataset` `#offline-rl` `#evaluation`

## Reinforced Conversational Rec

### UNICORN: Unified Conversational Recommendation Policy Learning via Graph-Based Reinforcement Learning
- **Authors:** Deng et al.
- **Venue:** ACL 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2106.10498)
- **Summary:** Unified RL policy over a knowledge-graph-based conversation graph for conversational recommendation; the agent decides when to ask clarifying questions vs. recommend items, using graph structure to guide dialogue strategy.
- **Tags:** `#conversational-rec` `#knowledge-graph` `#dialogue` `#rl`
