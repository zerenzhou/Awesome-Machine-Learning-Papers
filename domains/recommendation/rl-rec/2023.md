# 2023 — Reinforcement Learning for Recommendation Papers

2023 sees LLM-augmented RL agents for recommendation, improved offline RL with diffusion-based behavior cloning (SSD4Rec), and EGPG's evolving graph-guided policy gradient. The debate between model-based and model-free RL in recommendation intensifies with simulation-based training at scale.

## LLM-augmented RL Agent

### RecAgent: A LLM-powered Simulation Agent for Recommendation
- **Authors:** Wang et al.
- **Venue:** arXiv 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2306.02552)
- **Summary:** Uses LLM as a user simulation agent that generates realistic user preferences, responses, and conversational feedback for recommendation RL training environments; enables scalable simulation of diverse user behaviors without real user data collection.
- **Tags:** `#recagent` `#llm` `#simulation` `#user-agent`

## Evolved Graph Policy Gradient

### EGPG: Evolving Graph-based Policy Gradient for Recommendation
- **Authors:** (search: EGPG evolving graph policy gradient recommendation 2023)
- **Paper:** (search: evolving graph policy gradient reinforcement learning recommendation 2023 SIGIR KDD)
- **Summary:** Constructs a dynamically evolving user-item interaction graph updated at each RL step, using graph neural network policy to select items by propagating policy gradients through the graph structure; captures temporal evolution of user interests during recommendation sessions.
- **Tags:** `#egpg` `#graph-rl` `#policy-gradient` `#temporal`

## Diffusion-based Offline RL

### Diffusion-based Reinforcement Learning for Offline Recommendation
- **Authors:** (search: diffusion reinforcement learning offline recommendation 2023)
- **Paper:** (search: diffusion policy offline RL recommendation 2023 SIGIR RecSys)
- **Summary:** Applies diffusion models as behavior-cloning priors in offline RL for recommendation, using the denoising process to model the distribution of good recommendation policies from logged data and constrain policy search to high-density regions of the behavior space.
- **Tags:** `#diffusion` `#offline-rl` `#behavior-cloning`

## Safe / Conservative Policy Learning

### Conservative Offline Distributional Reinforcement Learning
- **Authors:** (search: conservative offline distributional reinforcement learning recommendation 2023)
- **Paper:** (search: distributional RL recommendation offline safe 2023)
- **Summary:** Extends CQL to distributional value estimates for recommendation, maintaining a distribution over Q-values rather than point estimates; the distributional pessimism enables more nuanced conservative offline policy learning that avoids catastrophic actions in sparse-reward recommendation settings.
- **Tags:** `#distributional-rl` `#offline-rl` `#conservative`
