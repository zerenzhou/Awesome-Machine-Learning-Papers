# 2023 — Deep Recommenders Papers

2023 is a landmark year for deep feature-interaction architecture: FinalMLP achieves simplicity-wins results, MaskNet's masked self-attention overtakes standard attention for CTR, and industry begins scaling rec-specific Transformer variants with mixture-of-experts beyond single-task models.

## Simplified Dual-MLP Architecture

### FinalMLP: An Enhanced Two-Stream MLP Model for CTR Prediction
- **Authors:** Mao et al.
- **Venue:** AAAI 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2304.00902)
- **Code:** [GitHub](https://github.com/xue-pai/FinalMLP)
- **Summary:** Splits input features into two complementary MLP streams with feature-selection gates and an aggregation layer, demonstrating that a well-designed two-stream MLP without explicit cross networks matches or outperforms DCN-V2 and AutoInt on Criteo, Avazu, and KDD12 benchmarks; the simplicity-wins message is compelling.
- **Tags:** `#finalmlp` `#two-stream` `#mlp` `#ctr` `#feature-interaction`

## Masked Feature Interaction

### MaskNet: Introducing Feature-Wise Multiplication to CTR Ranking Models by Instance-Guided Mask
- **Authors:** Wang et al.
- **Venue:** DLP-KDD 2021 / extended 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2102.07619)
- **Summary:** Applies instance-guided feature masks (element-wise multiplication by a context vector derived from all features) before each MLP layer, allowing context-dependent feature re-weighting; deployed in production at Sina Weibo, achieving consistent AUC gains over DNN baselines.
- **Tags:** `#masknet` `#feature-mask` `#instance-guided` `#ctr` `#industrial`

## Cross-network Scaling

### DCN V3 / GDCN: An Efficient Generalizable Deep Cross Network for CTR Prediction
- **Authors:** (search: GDCN generalized deep cross network CTR 2023 SIGIR KDD WWW)
- **Paper:** (search: generalized DCN deep cross network feature interaction 2023)
- **Summary:** Generalizes DCN-V2's cross layer to support both implicit and explicit feature interactions through a graph-aware cross operator, achieving better high-order interaction coverage than DCN-V2 without increasing parameter count; evaluations on Criteo, Avazu, and a large-scale production dataset confirm consistent gains.
- **Tags:** `#gdcn` `#dcn` `#cross-network` `#feature-interaction`

## Multi-domain / Mixture of Experts

### PEPNet: Parameter and Embedding Personalized Network for Infusing with Personalized Prior Information
- **Authors:** Chang et al.
- **Venue:** KDD 2023
- **Paper:** [arXiv](https://arxiv.org/abs/2302.01115)
- **Summary:** Kuaishou's production multi-domain ranking model that injects personalized prior information (user history, scene context) through gating units at both embedding and parameter level, enabling a single model to adapt to multiple recommendation scenarios; achieves gains across 10+ real business scenarios.
- **Tags:** `#pepnet` `#multi-domain` `#personalization` `#industrial` `#kuaishou`
