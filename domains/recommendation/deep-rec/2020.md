# 2020 — Deep Recommenders Papers

2020's highlights are GateNet's selective feature gating, IFM's factorization-machine with input-aware neurons, and the debut of AutoML-driven search over interaction architectures. The year also sees user behavior modeling extended to session-aware deep rec.

## Gating / Input-aware Feature Interaction

### GateNet: Gating-Enhanced Deep Network for Click-Through Rate Prediction
- **Authors:** Huang et al.
- **Venue:** arXiv 2020
- **Paper:** [arXiv](https://arxiv.org/abs/2007.03519)
- **Summary:** Introduces feature-level and bit-level gates applied after each feature embedding to suppress uninformative field dimensions before interaction; the embedding gate and hidden gate work complementarily to sharpen signal before DNN layers, improving AUC across multiple CTR datasets.
- **Tags:** `#gatenet` `#gating` `#feature-interaction` `#ctr`

### IFM: An Input-aware Factorization Machine for Sparse Prediction
- **Authors:** Yu et al.
- **Venue:** IJCAI 2020
- **Paper:** (search: IFM input-aware factorization machine sparse prediction Yu IJCAI 2020)
- **Summary:** Replaces shared FM feature weights with input-specific weights derived from a lightweight factor estimation network, allowing the FM interaction layer to dynamically scale each feature's contribution based on the current input context rather than learning globally fixed embeddings.
- **Tags:** `#ifm` `#fm` `#input-aware` `#feature-interaction`

## Automated Feature Interaction Architecture

### AutoFIS: Automatic Feature Interaction Selection in Factorization Models for Click-Through Rate Prediction
- **Authors:** Liu et al.
- **Venue:** KDD 2020
- **Paper:** [arXiv](https://arxiv.org/abs/2003.11235)
- **Summary:** Applies architecture search (GRDA optimizer) to select which pairwise feature interactions to include in FM-based models, pruning redundant pairs; demonstrates that automatic selection of a sparse interaction graph beats full second-order FM and deep models on Criteo and other benchmarks.
- **Tags:** `#autofis` `#nas` `#feature-selection` `#fm`

## Multi-task Learning

### Progressive Layered Extraction (PLE): A Novel Multi-Task Learning (MTL) Model for Personalized Recommendations
- **Authors:** Tang et al.
- **Venue:** RecSys 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3383313.3412236)
- **Summary:** Identifies "seesaw phenomenon" in MTL (improving one task hurts another) and proposes PLE's progressive extraction with task-specific and shared extraction networks combined via gating, outperforming MMoE on video recommendation at Tencent.
- **Tags:** `#ple` `#mtl` `#multi-task` `#gating` `#industrial`
