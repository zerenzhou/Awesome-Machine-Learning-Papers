# 2021 — Deep Recommenders Papers

2021's highlight is DCN-V2, which revamps the cross network with mixture-of-expert crossing and achieves state-of-the-art feature interaction with minimal overhead. The year also sees large-scale embedding table compression and transformer-based general recommenders.

## Cross-network Feature Interaction

### DCN V2: Improved Deep & Cross Network and Practical Lessons for Web-Scale Learning to Rank Systems
- **Authors:** Wang et al.
- **Venue:** WWW 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2008.13535)
- **Code:** [GitHub](https://github.com/shenweichen/DeepCTR)
- **Summary:** Replaces DCN's rank-1 weight matrix in the cross layer with a full-rank matrix (or mixture-of-low-rank), enabling richer explicit feature crossing; includes a mixture-of-experts variant (MoE-Cross) and shares production insights from Google's ranking systems.
- **Tags:** `#dcnv2` `#cross-network` `#feature-interaction` `#industrial`

### DESTINE: Dense Transformer for CTR Prediction
- **Authors:** Xu et al.
- **Venue:** CIKM 2021 (DESTINE / BERT-based deep rec)
- **Paper:** (search: DESTINE Dense Transformer CTR Prediction Xu CIKM 2021)
- **Summary:** Applies a dense Transformer variant to feature-field sequences in CTR prediction, using disentangled self-attention to separate feature-to-feature and position-to-position interactions, outperforming AutoInt with fewer layers.
- **Tags:** `#transformer` `#dense-attention` `#ctr`

## Embedding Table Compression

### Compositional Embeddings Using Complementary Partitions for Memory-Efficient Recommendation Systems
- **Authors:** Yin et al.
- **Venue:** KDD 2021
- **Paper:** [arXiv](https://arxiv.org/abs/1909.02107)
- **Summary:** Reduces embedding table memory footprint by representing each item ID as a composition of multiple sub-embeddings via complementary partitioning, achieving order-of-magnitude compression with negligible accuracy loss for large-scale industrial rec systems.
- **Tags:** `#embedding-compression` `#memory-efficient` `#industrial`

## Unified Deep Architecture

### Towards a Better Tradeoff between Effectiveness and Efficiency in Pre-Ranking Stage
- **Authors:** Wang et al.
- **Venue:** SIGIR 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2105.00372)
- **Summary:** COLD introduces a channel-wise lightweight deep network for the pre-ranking (filtering) stage, achieving a favorable balance between expressiveness and inference latency compared to both two-tower and full DNN rankers; deployed at Alibaba.
- **Tags:** `#pre-ranking` `#efficiency` `#industrial`

### AutoDebias: Learning to Debias for Recommendation
- **Authors:** Chen et al.
- **Venue:** SIGIR 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2105.04170)
- **Code:** [GitHub](https://github.com/DongHande/AutoDebias)
- **Summary:** Frames debiasing hyperparameter selection (IPS weights, propensity scores) as meta-learning, using a small unbiased validation set to automatically learn optimal debiasing configurations via bi-level optimization.
- **Tags:** `#debiasing` `#meta-learning` `#deep-rec`

### STAR: One Model to Serve All: Star Topology Adaptive Recommender for Multi-Domain CTR Prediction
- **Authors:** Sheng et al.
- **Venue:** CIKM 2021
- **Paper:** [arXiv](https://arxiv.org/abs/2101.11427)
- **Summary:** Uses a shared star topology where a common center network is combined with domain-specific networks via element-wise multiplication, enabling a single model to serve multiple recommendation domains simultaneously at Alibaba.
- **Tags:** `#star` `#multi-domain` `#multi-task` `#industrial`
