# 2022 — Deep Recommenders Papers

2022 sees Transformer architectures applied more broadly to feature interaction (ETA, BST maturation), and the emergence of efficient two-stage interaction models. AdaFM and masked autoencoders applied to rec features mark early directions toward foundation-model thinking in deep rec.

## Attention-based Interaction Evolution

### ETA: End-to-end Target Attention for Click-Through Rate Prediction
- **Authors:** Chen et al.
- **Venue:** KDD 2021 (widely benchmarked and extended in 2022)
- **Paper:** [arXiv](https://arxiv.org/abs/2108.04468)
- **Summary:** Extends SIM's two-stage retrieval with learned hash-based locality-sensitive hashing for fast approximate nearest-neighbor target-attention over very long user behavior sequences (10K+), enabling practical full-sequence attention at production-latency budgets.
- **Tags:** `#eta` `#target-attention` `#long-sequence` `#lsh` `#industrial`

### Adaptive Feature Interaction Modeling (AdaFM)
- **Authors:** (search: AdaFM adaptive feature interaction modeling recommendation 2022)
- **Paper:** (search: adaptive feature interaction deep recommendation 2022 SIGIR KDD)
- **Summary:** Learns to dynamically select interaction order (second-order vs. higher-order) per feature-field pair via a lightweight controller, avoiding over-parameterization from uniformly deep interaction stacks; provides both computation savings and improved accuracy over fixed-architecture deep rec models.
- **Tags:** `#adafm` `#adaptive` `#feature-interaction` `#ctr`

## Masked Autoencoder for Rec Features

### Contrastive Cross-domain Recommendation in Matching (CCDR)
- **Authors:** (search: CCDR contrastive cross-domain recommendation matching 2022)
- **Paper:** (search: contrastive cross-domain recommendation deep rec 2022 SIGIR)
- **Summary:** Bridges source and target domain recommendation via a cross-domain contrastive objective that aligns user and item embedding spaces without requiring overlapping users, using domain-specific decoders to prevent negative transfer between feature distributions.
- **Tags:** `#cross-domain` `#contrastive` `#domain-adaptation` `#deep-rec`

## Efficient Ranking Architecture

### Two-Pass Ranking: Ranking Efficiency via Pre-Ranking with Budget Attention
- **Authors:** (search: two-pass ranking pre-ranking budget attention deep recommender 2022)
- **Paper:** (search: two-stage pre-ranking deep recommendation efficiency 2022 industrial)
- **Summary:** Proposes a budget-constrained attention pre-ranker that scores candidates in O(1) feature-interaction cost by attending only to the top-K most informative feature dimensions, enabling a two-pass pipeline that preserves full-ranker accuracy while reducing latency.
- **Tags:** `#pre-ranking` `#efficiency` `#two-stage` `#attention`
