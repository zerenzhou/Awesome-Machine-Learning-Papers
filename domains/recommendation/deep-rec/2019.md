# 2019 — Deep Recommenders Papers

2019 is the attention-mechanism year for deep rec: AutoInt uses multi-head self-attention over feature fields, FiBiNET dynamically re-weights feature importance via SENET, and neural architecture search enters the feature-interaction design space.

## Attention-based Feature Interaction

### AutoInt: Automatic Feature Interaction Learning via Self-Attentive Neural Networks
- **Authors:** Song et al.
- **Venue:** CIKM 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1810.11921)
- **Code:** [GitHub](https://github.com/shichence/AutoInt)
- **Summary:** Applies multi-head self-attention with residual connections directly over feature embeddings, allowing the model to automatically learn which feature combinations are important for prediction; provides interpretable attention weights alongside strong CTR accuracy.
- **Tags:** `#autoint` `#attention` `#feature-interaction`

### FiBiNET: Combining Feature Importance and Bilinear Feature Interaction for CTR Prediction
- **Authors:** Huang et al.
- **Venue:** RecSys 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1905.09433)
- **Summary:** Integrates SENET (Squeeze-and-Excitation Networks from computer vision) to dynamically re-weight feature importance alongside bilinear feature interaction; shows that adaptive feature weighting prior to interaction is complementary to deep network depth.
- **Tags:** `#fibinet` `#senet` `#bilinear`

### Fi-GNN: Modeling Feature Interactions via Graph Neural Networks for CTR Prediction
- **Authors:** Li et al.
- **Venue:** CIKM 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1910.05552)
- **Summary:** Models each feature field as a node in a graph and uses GNN message passing to capture feature interactions, enabling flexible multi-hop interaction patterns beyond fixed-order FM extensions.
- **Tags:** `#gnn` `#feature-interaction` `#ctr`

## Neural Architecture Search for Rec

### AutoCross: Automatic Feature Crossing for Tabular Data in Real-World Applications
- **Authors:** Luo et al.
- **Venue:** KDD 2019
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3292500.3330679)
- **Summary:** Uses beam-search-based neural architecture search to find effective feature crossings for tabular CTR data, replacing manual feature engineering with automated cross-feature discovery at industry scale (Ant Financial).
- **Tags:** `#nas` `#feature-cross` `#industrial`

## Deep Embedding / Matching

### SDM: Sequential Deep Matching Model for Online Large-scale Recommender System
- **Authors:** Lv et al.
- **Venue:** CIKM 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1909.00385)
- **Summary:** Decomposes user history into short-term preference (LSTM) and long-term preference (attentive pooling), fusing both into a user representation for large-scale item matching in Taobao's two-tower retrieval system.
- **Tags:** `#sdm` `#matching` `#two-tower` `#industrial`

### Real-time Attention Based Look-alike Model for Recommender System (RALM)
- **Authors:** Liu et al.
- **Venue:** KDD 2019
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3292500.3330705)
- **Summary:** Builds a look-alike audience expansion model combining seed-user attention over a large user pool with real-time feature aggregation, enabling targeting of users similar to seed sets in advertising recommendation at Tencent scale.
- **Tags:** `#look-alike` `#attention` `#industrial`
