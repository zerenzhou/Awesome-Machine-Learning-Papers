# 2023 — Session-based Recommendation Papers

2023 session-rec is quieter as the paradigm converges with sequential rec. Key contributions are Atten-Mixer's multi-granularity attention fusion, CGSNet's cross-granularity session modeling, and the first systematic evaluation of LLMs for session-based cold-start recommendation.

## Multi-granularity Attention

### Atten-Mixer: Towards Enhancing Recommendation via Multi-granularity Attention Mixing
- **Authors:** Zhang et al.
- **Venue:** WSDM 2023
- **Paper:** (search: Atten-Mixer multi-granularity attention mixing recommendation WSDM 2023)
- **Summary:** Constructs hierarchical attention blocks that mix item-level and session-level representations by routing queries through granularity-specific attention modules; provides better trade-offs between local item-transition signals and global session intent than standard single-scale attention in NARM and STAMP.
- **Tags:** `#atten-mixer` `#multi-granularity` `#attention` `#session`

## Cross-granularity Session Modeling

### CGSNet: Cross-Granularity Session Network for Next-Item Recommendation
- **Authors:** (search: CGSNet cross-granularity session network next-item recommendation 2023)
- **Paper:** (search: cross-granularity session recommendation graph 2023 SIGIR KDD)
- **Summary:** Builds cross-granularity graphs connecting individual items, subsequences, and full sessions as nodes at different levels, then applies multi-level GNN message passing with cross-scale attention to capture both micro-transition patterns and macro-intent structure within sessions.
- **Tags:** `#cgsnet` `#cross-granularity` `#graph` `#session`

## LLMs for Session Recommendation

### Zero-Shot Next-Item Recommendation using Large Pretrained Language Models
- **Authors:** (search: zero-shot next-item recommendation large language model session 2023)
- **Paper:** (search: LLM zero-shot session-based recommendation 2023 arXiv)
- **Summary:** Evaluates GPT-4, LLaMA, and other LLMs as zero-shot session-based recommenders by formatting the current session as a natural-language prompt and asking for the next item; finds strong performance on popular items but significant degradation for tail items and long sessions, motivating hybrid ID + LLM session approaches.
- **Tags:** `#llm` `#zero-shot` `#session` `#evaluation`
