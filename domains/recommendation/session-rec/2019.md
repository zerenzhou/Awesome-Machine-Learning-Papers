# 2019 — Session-based Recommendation Papers

2019 is the graph year for session-based rec: SR-GNN models each session as a directed graph and applies gated graph neural networks to capture complex item transitions. FGNN follows with edge-weight learned graph attention, and NISER improves embedding normalization.

## Session-as-Graph

### Session-based Recommendation with Graph Neural Networks (SR-GNN)
- **Authors:** Wu et al.
- **Venue:** AAAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1811.00855)
- **Code:** [GitHub](https://github.com/CRIPAC-DIG/SR-GNN)
- **Summary:** Converts each session's item click sequence into a directed graph and applies gated graph neural networks (GGNN) to learn item embeddings enriched with transition structure; a soft attention readout then combines session-level and last-item representations for next-item prediction.
- **Tags:** `#srgnn` `#gnn` `#session` `#seminal`

### Rethinking the Item Order in Session-based Recommendation with Graph Neural Networks (FGNN)
- **Authors:** Qiu et al.
- **Venue:** CIKM 2019
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3357384.3358010)
- **Summary:** Adds a multi-headed weighted graph attention layer to the session graph, explicitly learning the importance of item-to-item transition edges; demonstrates that edge-weight learning captures ordering signals that GGNN propagation alone misses.
- **Tags:** `#fgnn` `#graph-attention` `#session`

### NISER: Normalized Item and Session Representations with Graph Neural Networks
- **Authors:** Gupta et al.
- **Venue:** CIKM 2019 Workshop
- **Paper:** [arXiv](https://arxiv.org/abs/1909.04276)
- **Summary:** Identifies that SR-GNN suffers from embedding magnitude domination and proposes L2-normalized item and session representations; simple normalization consistently improves GNN-based session models across multiple benchmarks without architecture changes.
- **Tags:** `#niser` `#normalization` `#gnn` `#session`

## Position-aware / Intent

### Price-aware Recommendation with Graph Convolutional Networks
- **Authors:** Zheng et al.
- **Venue:** ICDE 2020 (developed 2019)
- **Paper:** (search: price-aware recommendation graph convolutional network Zheng ICDE 2020)
- **Summary:** Incorporates item price signals into GCN-based session recommendation, jointly modeling user price sensitivity and item graph structure for e-commerce session modeling.
- **Tags:** `#price` `#gnn` `#session` `#e-commerce`

## Cross-session Propagation

### Repeat and Explore: Life-Long Summarized Reference for E-commerce Recommendation
- **Authors:** Ren et al.
- **Venue:** arXiv 2019
- **Paper:** (search: Repeat Explore Life-Long Summarized Reference E-commerce Recommendation Ren 2019)
- **Summary:** Models both the repeat consumption pattern (users revisiting previously bought items) and exploration of new items in session recommendation, showing that repeat consumption is a strong but underutilized signal in session-based models.
- **Tags:** `#repeat-consumption` `#exploration` `#session`

## Hierarchical / Global Graph

### Graph Contextualized Self-Attention Network for Session-based Recommendation (GC-SAN)
- **Authors:** Xu et al.
- **Venue:** IJCAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1905.08076)
- **Summary:** Combines graph neural network item representation with multi-head self-attention over the session sequence, bridging SR-GNN's graph perspective with BERT4Rec-style Transformer sequence modeling in a unified session-based architecture.
- **Tags:** `#gcsan` `#self-attention` `#gnn` `#session`
