# 2025 — Session-based Recommendation Papers

2025 is a minimal year for standalone session-rec as the paradigm largely merges with sequential rec and LLM4Rec. The remaining session-specific contributions focus on privacy-preserving anonymous sessions and test-time adaptation for cold-start sessions.

## LLM-guided Session Rec

### LLM-Session: Leveraging Language Models for Cold-Start Anonymous Session Recommendation
- **Authors:** (search: LLM cold-start anonymous session recommendation 2025)
- **Paper:** (search: language model session-based recommendation cold-start anonymous 2025 SIGIR KDD)
- **Summary:** Uses an LLM to generate item-description embeddings for the current session items as a semantic summary, then retrieves similar historical sessions from a session index using this semantic representation; significantly improves next-item prediction for very short (1–2 item) anonymous sessions without user ID.
- **Tags:** `#llm` `#cold-start` `#session` `#anonymous` `#semantic`

## Privacy-preserving Session Rec

### FedSession: Federated Learning for Session-based Recommendation
- **Authors:** (search: federated learning session-based recommendation privacy 2025)
- **Paper:** (search: federated session recommendation privacy-preserving 2025 WWW RecSys)
- **Summary:** Proposes a federated session recommendation framework where session history never leaves user devices; a lightweight session GNN is trained locally and only gradient updates with differential privacy noise are shared, achieving on-device personalization without centralized session data collection.
- **Tags:** `#federated` `#privacy` `#session` `#on-device`
