# 2024 — Session-based Recommendation Papers

2024 session-rec is small but purposeful: HMNet's hierarchical multi-view network and MiaSRec's multi-interest approach represent the mature state of graph-based session methods. Research effort is shifting toward session-level LLM integration as the new frontier.

## Hierarchical Multi-view Session Modeling

### HMNet: Hierarchical Multi-view Network for Session-based Recommendation
- **Authors:** (search: HMNet hierarchical multi-view session-based recommendation 2024)
- **Paper:** (search: hierarchical multi-view network session recommendation 2024 SIGIR KDD WWW)
- **Summary:** Constructs session representations from three complementary views (sequential, graph, and co-occurrence) via hierarchical fusion, then selects the most informative view per session via a learned view-routing gate; outperforms single-view approaches on both short and long sessions.
- **Tags:** `#hmnet` `#hierarchical` `#multi-view` `#session`

## Multi-interest Session Modeling

### MiaSRec: Multi-Interest Aware Session-based Recommendation
- **Authors:** (search: MiaSRec multi-interest session-based recommendation 2024)
- **Paper:** (search: multi-interest session recommendation 2024 AAAI IJCAI SIGIR)
- **Summary:** Disentangles multiple latent interests within a session using iterative routing (capsule-style), assigning each session item to one of K interest capsules; the most relevant interest capsule is selected at inference via target-item attention, improving next-item prediction for diverse-intent sessions.
- **Tags:** `#miasrec` `#multi-interest` `#capsule` `#session`
