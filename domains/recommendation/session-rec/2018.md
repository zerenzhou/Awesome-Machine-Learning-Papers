# 2018 — Session-based Recommendation Papers

2018 elevates session-based rec beyond pure RNNs: NARM augments GRU with item-level attention to capture sequential purpose, while STAMP completely abandons sequential RNN in favor of attention over the full session, demonstrating that Transformer-style self-attention can outperform recurrence for short sessions.

## RNN + Attention

### Neural Attentive Session-based Recommendation (NARM)
- **Authors:** Li et al.
- **Venue:** CIKM 2017
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3132847.3132926)
- **Code:** [GitHub](https://github.com/lijiani94/NARM)
- **Summary:** Adds a local attention mechanism to GRU that re-weights hidden states according to their relevance to the final hidden state, capturing the session's sequential purpose; significantly outperforms vanilla GRU4Rec on e-commerce session benchmarks.
- **Tags:** `#narm` `#rnn` `#attention` `#session`

### STAMP: Short-Term Attention/Memory Priority Model for Session-based Recommendation
- **Authors:** Liu et al.
- **Venue:** KDD 2018
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3219819.3219950)
- **Summary:** Discards GRU entirely; models user short-term intent via self-attention over all session items plus attention with the last clicked item, demonstrating that short-term memory priorities captured by pure attention beat recurrent models on several benchmarks.
- **Tags:** `#stamp` `#attention` `#short-term` `#session`

## Convolutional Session Modeling

### Improved Session-based Recommendation with Dynamic Graph Neural Networks (CSRM)
- **Authors:** Wang et al.
- **Venue:** (search: Collaborative Memory Network Session-based Recommendation CSRM Wang 2019)
- **Paper:** (search: CSRM collaborative memory session recommendation 2019)
- **Summary:** Extends session RNNs with a collaborative memory module that retrieves similar neighbor sessions from a memory bank, augmenting the current session representation with collective behavior patterns across sessions.
- **Tags:** `#memory` `#collaborative` `#session`

## Cross-session / Neighborhood

### Session-based Social Recommendation via Dynamic Graph Attention Networks
- **Authors:** Song et al.
- **Venue:** WSDM 2019
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3289600.3290989)
- **Summary:** Integrates social network signals with session-based recommendation via dynamic graph attention, propagating friend influence over a time-evolving social graph to augment session item representations.
- **Tags:** `#social` `#graph-attention` `#session`

## Gating / Position-aware

### A Review-Driven Neural Model for Sequential Recommendation
- **Authors:** Liu et al.
- **Venue:** IJCAI 2019
- **Paper:** [arXiv](https://arxiv.org/abs/1907.00590)
- **Summary:** Fuses review text with session interaction sequences via gated review attention, showing that textual sentiment in user reviews complements interaction sequences for predicting the next item, especially in cold-start scenarios.
- **Tags:** `#review` `#text` `#session` `#multimodal`
