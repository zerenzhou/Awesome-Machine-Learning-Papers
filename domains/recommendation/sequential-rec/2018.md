# 2018 — Sequential Recommendation Papers

CNN and attention architectures enter the field: Caser models sequences as images, SHAN adds hierarchical attention, and GRU4Rec receives a refined loss function update; the stage is set for SASRec (see classic.md).

## CNN-based

### Personalized Top-N Sequential Recommendation via Convolutional Sequence Embedding (Caser)
- **Authors:** Tang & Wang
- **Venue:** WSDM 2018
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3159652.3159656)
- **Code:** [GitHub](https://github.com/graytowne/caser_pytorch)
- **Summary:** Treats the recent item-embedding matrix as a 2-D "image" and applies horizontal + vertical convolutional filters to capture union-level and point-level sequential patterns, outperforming RNN baselines on several benchmarks.
- **Tags:** `#cnn` `#sequential` `#top-n`

## Attention / Hierarchical

### Sequential Recommender System based on Hierarchical Attention Network (SHAN)
- **Authors:** Ying et al.
- **Venue:** IJCAI 2018
- **Paper:** [IJCAI Proceedings](https://www.ijcai.org/proceedings/2018/546)
- **Summary:** Stacks two levels of attention — one over the full long-term history, one over the recent short-term window — to separately capture long-range preferences and immediate session intent.
- **Tags:** `#attention` `#hierarchical` `#sequential`

### Attention-based Transactional Context Embedding for Next-Item Recommendation (ATCE)
- **Authors:** Zhang et al.
- **Venue:** AAAI 2018
- **Paper:** (search: Attention-based Transactional Context Embedding for Next-Item Recommendation AAAI 2018)
- **Summary:** Combines attention over transactional context with latent factor models to capture the asymmetric co-occurrence of items in sequential purchases.
- **Tags:** `#attention` `#context` `#next-item`

## RNN / Loss Function

### Recurrent Neural Networks with Top-k Gains for Session-based Recommendations
- **Authors:** Hidasi & Karatzoglou
- **Venue:** CIKM 2018
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3269206.3271761)
- **Summary:** Revisits GRU4Rec loss design, showing that carefully constructed listwise top-k loss functions yield substantial ranking gains; provides an improved training recipe widely adopted for RNN-based session recommenders.
- **Tags:** `#rnn` `#session-based` `#loss-function` `#top-k`

## Memory / External

### Memory-Augmented Neural Networks for Next-Item Recommendation (MANN)
- **Authors:** Chen et al.
- **Venue:** RecSys 2018
- **Paper:** (search: Memory-Augmented Neural Networks for Next-Item Recommendation RecSys 2018)
- **Summary:** Augments RNN-based sequential models with an external addressable memory to maintain an explicit, persistent user-preference representation that is read and written at each step.
- **Tags:** `#rnn` `#memory-network` `#sequential`
