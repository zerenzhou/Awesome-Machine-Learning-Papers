# 2020 — Sequential Recommendation Papers

Self-supervised pre-training meets sequential rec: TiSASRec adds continuous time modeling, S³-Rec aligns item attributes with behavior through mutual information, and contrastive/disentangled ideas begin to permeate the field.

## Transformer / Time-aware

### Time Interval Aware Self-Attention for Sequential Recommendation (TiSASRec)
- **Authors:** Li et al.
- **Venue:** WSDM 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3336191.3371786)
- **Code:** [GitHub](https://github.com/JiachengLi1995/TiSASRec)
- **Summary:** Extends SASRec by injecting absolute and relative time-interval information directly into the self-attention mechanism, allowing the model to weight recent interactions more appropriately and capturing temporal dynamics without manual time-binning.
- **Tags:** `#transformer` `#time-aware` `#sequential`

### MEANTIME: Mixture of Attention Mechanisms with Multi-temporal Embeddings for Sequential Recommendation
- **Authors:** Cho et al.
- **Venue:** RecSys 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3383313.3412216)
- **Code:** [GitHub](https://github.com/kakaoenterprise/MEANTIME)
- **Summary:** Combines multiple time-scale embeddings with a mixture of self-attention heads to simultaneously capture long-term trends and short-term shifts in user preference, outperforming TiSASRec on temporal benchmarks.
- **Tags:** `#transformer` `#time-aware` `#multi-scale`

## Self-supervised / Pre-training

### S³-Rec: Self-Supervised Learning for Sequential Recommendation with Mutual Information Maximization
- **Authors:** Zhou et al.
- **Venue:** CIKM 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3340531.3411954)
- **Code:** [GitHub](https://github.com/RUCAIBox/RECBOLE)
- **Summary:** Proposes four self-supervised pre-training objectives (item–attribute, segment–item, segment–attribute, item–item correlation) based on mutual information maximization to enrich item representations before fine-tuning SASRec-style models.
- **Tags:** `#ssl` `#pre-training` `#transformer` `#mutual-information`

### Parameter-Efficient Transfer from Sequential Behaviors for User Modeling and Recommendation (PeterRec)
- **Authors:** Yuan et al.
- **Venue:** SIGIR 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3397271.3401323)
- **Summary:** Pre-trains a sequential recommendation model on large-scale user-behavior logs and then transfers it to multiple downstream tasks via lightweight graph-based adapter networks, achieving strong few-shot performance with minimal task-specific parameters.
- **Tags:** `#pre-training` `#transfer-learning` `#sequential` `#industrial`

## Disentangled / Latent-Intent

### Disentangled Self-Supervision in Sequential Recommenders (DSSRec)
- **Authors:** Ma et al.
- **Venue:** KDD 2020
- **Paper:** [ACM Digital Library](https://dl.acm.org/doi/10.1145/3394486.3403091)
- **Summary:** Introduces disentangled self-supervision that separates user intent factors from noise in interaction sequences, learning independent intent-specific representations via mutual information-based objectives; significantly improves robustness on noisy interaction data.
- **Tags:** `#ssl` `#disentangled` `#sequential`

## Graph-augmented

### Memory Augmented Graph Neural Networks for Sequential Recommendation (MA-GNN)
- **Authors:** Ma et al.
- **Venue:** AAAI 2020
- **Paper:** (search: Memory Augmented Graph Neural Networks Sequential Recommendation AAAI 2020 Ma)
- **Summary:** Augments GNN-based session encoding with an external memory module that stores long-term user preference signals across sessions; the memory enables the GNN to reference patterns from the full user history, not just the current session graph.
- **Tags:** `#gnn` `#memory-network` `#sequential` `#cross-session`
